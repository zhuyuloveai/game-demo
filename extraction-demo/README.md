# 我的宇宙（暂定名）

更新于 2026-10-14。引擎已确定为 Godot，进入独立玩法 demo 验证阶段。首个航海与港口交易 demo 已可运行试玩。

## 长期愿景

用户希望拥有一个属于自己的游戏世界。初期可以做的事情较少、体验尚不完善；随着持续制作，自己爱做的事情能够越来越有意思、越来越丰富。

核心偏好是广义的角色扮演：代入一个新角色，在世界中行动、经历事情。搜打撤、航海、贸易、经营和动作战斗可以同等重要；它们的组合与最终游戏形式继续通过讨论和试玩寻找。

最新愿景是能够自由穿梭不同的时代、世界、身份与体验尺度。用户以《Rick and Morty》中的 Rick 作比喻：按照当下的兴趣，通过时光机等入口进入想体验的背景。这里的“无限”表达持续扩展的愿望，初期内容可以很小。

用户举出的体验包括：

- 回到旧时代，进行《大航海时代》式的航行、贸易与冒险。
- 进入现代战争背景。
- 来到未来，探索宇宙。
- 在一座城市里扮演普通市民。
- 扮演科学家，研究微生物，也能探索微生物尺度的体验。

用户进一步明确：无论进入哪个时代或世界，始终是同一个“我”。不同体验之间需要有关联，有一条贯穿始终的主线，并且能够留下持续的积累。

主线的具体故事、积累的种类与跨世界使用规则、进入与离开方式、不同世界的时间是否推进，均尚未确定。上述体验是未来入口的候选，不是首版同时实现的承诺。

## 用户已经明确的偏好

- 喜欢搜打撤。
- 喜欢《大航海时代》式的大世界航行、探险和港口间贸易。
- 喜欢登陆战加入简单的动作或格斗元素，以《铸剑物语》的效果为参考，复杂度保持克制。
- 《大航海时代》、搜打撤、《大富翁》和《铸剑物语》的共同吸引力，是把自己代入一个新的角色。
- 愿意分别试做喜欢的元素，并同步讨论最终游戏形式。
- 希望世界能够长期扩展，逐步丰富自己喜欢的活动。
- 跨世界始终保持自我的连续性，各段经历共同构成同一个人的故事。
- 希望有贯穿始终的主线，让不同世界的体验发生联系。
- 希望冒险能留下持续积累；具体包括哪些能力、知识、资产、关系或世界变化，继续讨论。
- 希望以较低制作成本支持丰富的场景和视角，同时保持良好的游戏体验。
- 希望未来志同道合的玩家可以制作自己想体验的场景和剧情。
- 软件架构可参考 iCode Teams 的插件形式，同时借鉴游戏行业的内容扩展实践。

## 已确定的技术与推进方式

用户已选择 Godot，并明确先单点制作几个玩法 demo，再根据实际体验决定框架如何组织。首个 demo 选择“航海与港口交易：航行、买卖、补给、带回收益”。原型采用 Godot 4 + GDScript，以桌面试玩为当前验证入口；最终发行平台仍待确定。

各 demo 独立运行，允许保留少量重复代码。先验证具体玩法中的选择、反馈和继续玩的动力，等多个 demo 出现实际的共同需求，再决定复用边界。

共享核心、玩法模块、世界与剧情内容包、创作者工具保留为长期架构候选；跨世界存档、插件协议和通用编辑器安排在试玩之后讨论。

## 首个玩法 demo：航海与港口交易

项目位置：`prototypes/sailing-trade/`。具体运行方式见该目录的 README。

### 本轮确定范围（2026-10-14）

用户认为首版三港固定买卖原型远远不够。参考《大航海时代 IV》实际场景与绘图表现后，明确先细化并实现航行、港口、贸易、船只。剧情与探索、海战和势力竞争暂缓。

v2 已连接可自由驾驶的海上场景、三座有独立绘景和设施入口的港口、六种商品的库存与行情变化，以及船只命名、修理、扩仓和换船。支持自动航行、手动靠泊及本地继续存档。默认入口已切换为 `scenes/voyage.tscn`，本地可双击 `prototypes/sailing-trade/launch.command` 试玩。框架继续留待实际玩法验证。

### 首版原型记录

- 一艘船、三个港口、三种商品，使用固定且可查询的买卖价。
- 完整体验：查看行情 → 购货 → 安排航线与补给 → 航行 → 到港出售 → 带回收益 → 扩建货舱。
- 观察：是否愿意比较路线与货舱用途？利润是否带来跑下一趟的期待？补给能否产生可理解的取舍？
- 原型暂以独立单局验证，失败可救援，随时可重新开始。
- 首轮重点体验航行与贸易；战斗、跨世界角色传承及玩家创作工具在后续独立验证。

其他候选 demo 为搜集与撤离、小场景角色生活；其具体范围和实现顺序待试玩后讨论。

## 当前背景与战斗讨论

- 《全职猎人》和《海贼王》的世界观都讨论过，用户认可过海贼航海方向；航海现为跨世界愿景中的一个候选体验，具体背景、主角身份、主线和与原作的关系仍待明确。
- 最早提出回合制自动战斗，后来讨论过割草战斗和《铸剑物语》式轻量横版动作战。具体战斗方案尚未最终选定。
- 《孢子》已被提及；用户尚未说明具体喜欢它的哪些部分。

## 建议的推进方式（供后续讨论与试玩验证）

1. 从用户描述的具体体验出发，为某个元素做小型可玩原型。
2. 用试玩发现乐趣、重复游玩的动力和负担，再决定如何深化。
3. 在各个世界内部逐步连接活动、地点、物品和经历，并让跨世界经历共同推进主线与长期积累；具体连接方式另行讨论。
4. 每轮改善一件已经能做的事，或增加一个与已有生活有联系的新机会。
5. 根据实际兴趣安排实现顺序，让不同活动保留各自的发展空间。
6. 每个新世界逐步形成自己的可玩生活，同时围绕同一个主角，探索故事、积累和因果关系如何贯穿不同世界。

首个可玩方向与引擎已确定。最终游戏形式、跨世界存档、长期成长方式以及正式游戏的失败代价，继续通过讨论与试玩确定。
