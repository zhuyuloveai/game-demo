# Puppy blink and paw animation

Generated with the built-in imagegen tool, using the existing `puppy.webp` as the edit target. The production asset is `kitchen-merge/dist/assets/cabinet-v5/ui/puppy-idle-v1.webp` (880×448 RGBA, eight 220×224 cells). The original generated image is preserved in `generated-sheet.png`; `prepare.py` only crops, resizes, packs and encodes the authored frames.

The game renders 55×56 cells. It rests for 21.6 seconds, then plays a 2.4-second blink and paw wave. It uses frame changes without character translation, rotation or scale. Interaction reactions are limited to one per 12 seconds. Hidden pages and dialogs pause the animation; reduced-motion mode shows the resting frame. The short `puppy-actions-preview.webp` demonstrates the poses with an abbreviated resting interval; `puppy-animation.webp` includes the production interval.
