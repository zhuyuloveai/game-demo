## 文件与用途

- `delivery-manifest.json`：逐件 ID、名称、识别特征、两套文件、最终提示词、格内尺寸及验收证据。
- `sources/`：内置 imagegen 逐件生成的透明原图。
- `items/`：保留原 alpha 的 512px PNG 与 160px WebP；逐件按实际边界裁切，无图集均分。
- `classic/`：397 张独立 SVG 插画导出。正式游戏使用 `kitchen-merge/dist/chain-classic-art.mjs` 和布局测量文件，延续经典材质系统。
- `prompts/`、`records/`：生成提示词、返修版本、原始图路径、裁切边界与视觉记录。最终提示词以每件 record 的 `prompt` 为准。
- `references/`、`reference-map.json`：风格与角色参考、返修前的准确输入图。
- `sources/rejected/`、`records/rejected/`：返修前版本，供追溯。
- `evidence/`：逐链大图、44px 双风格检查表、浏览器截图、几何和存档一致性检查。

## 接入和验证

53 条既有链的物品、生产器名称与配方标题已同步。ID、等级数、数值、合成关系、掉率、配方输入输出和存档结构保持原值。完整规则差异见 `evidence/gameplay-invariants.json`。

经典与新版均在 375×667 实际浏览器中检查；7×9 共 63 格，经典 46×46、新版 44×44，行列额外间隔均为 0，无整页溢出。切换风格前后，棋盘与资源显示一致。全部 397 件分别检查大图和实际小尺寸，返修了重复包、奖章轮廓、物体裁边、相册主体和提前长出植物等问题。
