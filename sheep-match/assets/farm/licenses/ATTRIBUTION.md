# 素材来源与署名

本包逐文件来源以manifest中licenseIds与sourceRefs为准，不能把整包误标CC0。

- Kenney RPG Base，Kenney Vleugels，https://kenney.nl/assets/rpg-base ，CC0 1.0，https://creativecommons.org/publicdomain/zero/1.0/ 。如使用原路径，修改含颜色、轮廓、房体组合与比例。
- Animal artwork adapted from “Animals pack” by Olga Bikmullina (AhNinniah), https://opengameart.org/content/animals-pack , licensed CC BY 3.0, https://creativecommons.org/licenses/by/3.0/ . The accepted style preview used an extracted cow head. This full asset pack uses newly constructed cow/pig paths and retains the original reference credit; no original Olga paths are copied into the final animal SVGs. Do not confuse reference provenance with actual path reuse. Preserve this notice with the pack.
- SHMECTOR.COM “Set of vegetables”，https://shmector.com/free-vector/nature/set_of_vegetables/9-0-1686 ，作者页声明CC0 1.0。采用时为EPS转纯向量SVG后裁切、调色和描边修改，不是预览位图描摹。
- Existing project icons retain original project provenance. New vector artwork is separately identified; no blanket third-party relicensing.

请以实际产出记录为准，最终整包只列确实使用的来源；没有使用的参考不冒充资产作者。
