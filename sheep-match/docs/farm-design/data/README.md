# 羊羊牧场 核心农场参数与复算包 v0.4

与同版设计方案一起阅读。全部内容是设计提案，不是已实现游戏；研究日期2026-10-24。仅含核心种植、动物、加工、交易、仓储、扩地和三消联动，不包含未采纳后期系统。

## 两层配置

- project-parameters-v04.json 是羊羊牧场项目默认配置，参考快照的采纳值与原创适配均有标记。48个生产商品、11田作物、5果树/灌木、13建筑实例及5种动物。referenceId 是追溯键，projectId/name 是项目表现键。
- hayday-production-parameters.json 与带 source 的 CSV 是核心范围参考快照，current 字段为空代表未核实，不等于0或免费。原作M10缺失时不回写猜值；本地价格在project配置独立记录。
- hayday-levels-1-30.csv 的经验和田额度是社区历史参考，本项目明确采纳为初始设计基线，不代表2026当前完整田数/奖励。主要解锁列按本次核心范围过滤。
- project-item-catalog.csv 便于策划查价。project-land-patches.csv 是原创64×64地图的48个8×8扩地区块，不是原作地图。
- linkage-rewards.json 是本项目24关设计目标与一次性奖励，不是Hay Day原生功能。它不含已经制作完成的棋盘坐标或可解种子池。
- sources-register.csv 为直接来源链接索引。官方机制、社区快照、未知值和本地适配不得互相替换标签。

## 复算

Python 3，无第三方依赖。在本目录运行（脚本也支持从其他工作目录调用）：

    python audit_hayday_adaptation.py
    python check_project_config.py

第一项生成三个固定30分钟策略的逐操作CSV、结果JSON、救济比较和价格检查。随手/勤快/混合期末现金为184/354/284；含初始赠与及升级赠种变现，不是净利润或玩家预测。33项原有M10核价共3300次检查；加26项本地补价后核心59项共5900次原样交易检查，已包括熟练度金币封顶。每个数量范围1至100。

第二项检查核心ID/配方依赖、地图不重叠且总4096格、三种土地材料各624件、24关预算5140金币估值，以及水果/熟练度组合报价不超过NPC买价。输出project-validation-results.json。通过静态断言不证明所有长期经济已平衡。

hayday-static-checks.csv/json 保留15个明确加工机会成本算例。它们以参考最高挂牌价估值，不保证实际成交。机会增值不等于现金利润，基础时长不等于三星时长。

## 重要限制

没有真实玩家测试、现版客户端逐项抓取、完整30级长期现金流或随机材料P95模拟。NPC成交、工具掉落、订单生成、建设券与肥料是本地适配。无真钱、联网市场、服务器防作弊或跨设备同步。所有价格单位金币，时间配置统一毫秒，来源表明确分钟。后续改参数应同时更新方案、项目JSON和复算结果，不能只改界面常量。
