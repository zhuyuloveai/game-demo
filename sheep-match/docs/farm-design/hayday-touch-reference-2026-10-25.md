# Hay Day 触控对照与本项目验收边界

核对日期：2026-10-25。对照基线为本项目 GDD 第16、17章，以及本轮更新后的 `farm-ui.mjs` / `farm-gestures.mjs`。下表“当前实现”是代码能力，浏览器执行结果另见实施验收记录；不能将实现说明替代已执行测试。

结论：经营循环参考 Hay Day，但更新后的触控入口仍不是一比一。已靠近“点对象、出现形象工具、拖动操作”的直接感，不为追求复刻修改既定经济、存档和正交地图。

## 最小可落地改进

1. 点田后直接显示作物图标和镰刀，不先开一大页说明。工具被拖动时跟随手指，目标有简洁高亮；底部仍显示当前工具。
2. 动物和机器用饲料袋、蛋篮、产物和配方图标表达动作，计时/库存保持短文本。多批收取与整栏喂养作为便捷入口，不把整个经营流程变成管理表格。
3. 空地单指拖图；对象工具拖动不拖地图。仍沿用现有去重、快速线段补点、缺库存部分执行、UI越界取消与原子落盘，不引入原作未证的“边划边永久扣资源”。
4. 不增加多层新手教学。常态只给一句就地提示，例如“拖种子到空田”“拖镰刀收成熟作物”；复杂说明留帮助页。

## 浏览器手机视口应验收的项目合同

- 小屏上点对象、工具拖田、跨多田快速划、往返不重复扣种；空田和成熟田工具是否正确。
- 地图单指拖动不误开对象；双指加入取消未提交笔画；缩放结束剩一指不自动续种。
- 手指划进固定栏、弹窗或视口外，取消本笔；面板滚动不穿透地图。
- 缺种、缺饲料、仓满只执行可执行目标；取消预览不扣资源；成功后刷新不重复经济事务。
- 布置选中、拖动、旋转、非法落位、保存、取消；生产计时和已有队列不丢失。
- 商店未确认不扣钱；机器入队/领取、动物收取、订单都能在手机视口完整触达。

本轮用户要求是浏览器手机分辨率模拟，不要求真机。浏览器模拟通过只能证明对应环境与已执行用例，不能扩写成 iOS/Android 原生触摸、Safari 或 Hay Day 当前版本的实机认证。
