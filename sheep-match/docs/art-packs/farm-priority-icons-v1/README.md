# 农场常用图标 · 第一批

基于 main `0a8363f` 的常用物品和操作资源目录，补充 **67 个可编辑 SVG + 67 个透明 PNG**。延续奶油底色、暖棕描边、柔和绿和桃橙色，原图保留，未改游戏引用。

## 范围

| 分类 | 数量 | 内容 |
| --- | ---: | --- |
| `items/` | 26 | 11 种作物、5 种水果、5 种动物产物、5 种饲料 |
| `ui/` | 35 | 播种、收获、喂养、建造、布置、旋转、首页、仓库、商店、订单、任务等 |
| `tools/` | 6 | 奶桶、剪毛剪、收蛋篮、果篮、松露篮、香草篮 |

镰刀、种子袋、饲料袋通过 manifest 别名复用 `ui/harvest.svg`、`ui/sow.svg`、`ui/feed.svg`，不重复计数。数量、价格、倒计时、按钮状态均未画进图标。

## 尺寸与使用

- SVG `viewBox="0 0 128 128"`，PNG 256×256，中心锚点 `(64,64)` / PNG `(128,128)`；透明画布，保留外沿留白。
- 安全内容区为 SVG `(4,4,120,120)`；交互热区由代码设定，不能只用图形可见面积作为按钮范围。
- 推荐显示 32–64 CSS px；饲料物种和收取篮在紧凑界面需搭配动态名称，避免只靠小图判断。
- 可用 SVG 任意缩放；PNG 为 2 倍导出。不要将图标九宫格拉伸，按钮底板复用已合入的 `farm-ui-v1`。
- SVG 使用命名组，可分别编辑袋身、徽章、叶片、篮子等图层。`source/build-icons.py` 保留构图源代码；没有嵌入整张位图。

完整文件名、原路径映射、画布、推荐尺寸及别名见 `manifest.json`。工具为新增资源，`originalPath` 为 null；其他原路径相对于仓库根目录。

## 预览和重建

`index.html` 可筛选物品 / 操作 / 工具，并切换 80、48、32px。`previews/contact-sheet.png` 是完整总览，`previews/small-size.png` 为 40px 显示检查图。

```sh
python3 source/build-icons.py
node source/export-png.cjs
python3 ../sumikko-farm-v1/animal-animation-v2/source/verify-delivery.py
```

导出需要 `sharp`，可通过 `SHARP_MODULE` 指定模块路径；验证需要 Pillow。交付已检查 SVG XML、SHA-256、67 张 PNG 的尺寸/透明度/边界、原文件映射和别名。小尺寸总览已目视检查；修正了甘蔗叶片裁切和商店棚顶条纹越界。

本包仅是美术交付，没有修改运行时、没有部署线上。物品数量、按钮默认/禁用/选中状态继续由现有代码和 UI 组件包控制。
