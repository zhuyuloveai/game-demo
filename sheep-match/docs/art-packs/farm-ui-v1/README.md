## 本轮交付

**15 类组件、48 个独立透明 SVG 状态文件**，不含任何文案、价格、倒计时、数量或物品图标。完整对应文件与参数见 `manifest.json`。

| 组件 | 文件前缀 | 状态 |
| --- | --- | --- |
| 面板底板 / 标题 / 内容槽 / 分隔线 | `panel-` / `title-` / `well-` / `divider-` | 默认 |
| 主按钮 / 次按钮 / 关闭 | `button-primary-` / `button-secondary-` / `close-` | 默认、按下、禁用 |
| 页签 | `tab-` | 默认、选中、按下、禁用 |
| 物品格 / 配方卡 | `item-slot-` / `recipe-card-` | 默认、选中、按下、禁用、缺料 |
| 队列槽位 | `queue-slot-` | 空槽、生产中、等待、已完成、未解锁 |
| 数量标签 | `quantity-` | 默认、缺料、完成、禁用 |
| 进度条 | `progress-` | 轨道与填充分开 |
| 局部提示底板 | `notice-` | 普通、缺料、满仓、空状态 |
| 状态符号 | `symbol-` | 锁、勾、时钟、加号、提醒、箭头 |

`source/production-wide.svg`（1280×720）与 `source/production-mobile.svg`（400×740）为可编辑组合源，组件、每条文字、复用物品、背景参考均有独立命名图层。四个必要状态也有 `source/mobile-*.svg`。文本为 SVG `<text>`，没有转曲或栅格化。组件本身是可编辑矢量路径；复用物品保留原资源；农场截图只是组合参考层，不是运行时 UI 背景。

`previews/` 包含真实浏览器组合 PNG。`source/*-layout.json` 保存浏览器可见组件的坐标、尺寸、文本和字号，`export-artboards.py` 据此导出 SVG。单个图层可独立修改；字体或布局发生变化后应重新核对排版。

## 尺寸与拉伸

参数均为 1× CSS 像素；九宫格 `nineSlice` 顺序为 **上、右、下、左**。中心与边采用拉伸，角部不变形。`contentPadding` 与 `safeContentRect` 说明内容区域，按外框定位，不能把物品和文字合并进底板。

| 组件 | 源尺寸 | 切片 | 内容约定 |
| --- | --- | --- | --- |
| 面板 | 96×96 | 四边 26 | 安全内边距上／右／下／左 14／14／12／14；样板宽屏左右 20、手机左右 14 |
| 标题底板 | 96×64 | 四边 20 | 左右 16、上下 12 |
| 主 / 次按钮 | 96×48 | 四边 16 | 左右 18、上下 10；主要按钮显示高度 48 |
| 配方卡 | 112×104 | 四边 19 | 内容内缩 10；角标独立于文字 |
| 物品格 / 队列槽 | 72×72 / 80×80 | 四边 16 | 内容内缩 10 |
| 数量标签 | 64×28 | 四边 13 | 左右 8、上下 4 |
| 进度轨道 / 填充 | 96×16 | 四边 7 / 6 | 容器裁切填充宽度；百分比由代码决定 |

关闭按钮和状态符号等比缩放，不作九宫格。关闭按钮命中区至少 44×44；小图形可以放在较大的透明点击区域中。所有状态保持相同画布、锚点和安全区，按下态仅改变底板形状，文字位置不跳动。

宽屏样板使用右侧 500px 面板，保留约 61% 的地图宽度；手机面板留 8px 外边距，标题和主操作固定，中部在较矮视口独立滚动。400×740 的全部示例状态可完整显示主体内容。短屏滚动是排版规则，不需要新画一套素材。

## 复用与实际页面依据

- `reuse-manifest.json`：11 个现有物品 SVG＋1 个面包房 PNG 的原路径、交付副本和 SHA-256。全部逐字节复用。
- `environment-reuse-review.json`：12 个现有环境资源代表项，记录原路径、锚点与尺寸，无复制覆盖。
- `evidence/current-production-wide.png`、`current-production-mobile.png`：实际 main 的生产面板／原料详情截图。
- `evidence/farm-context-*.png`：使用正式渲染的隔离测试地图截图。未访问玩家存档。
- 已读取正式 `farm-scene-world.mjs` 的 `machineBoard`、配方详情和等待任务逻辑，以及 `farm-config.mjs` 的配方参数。

样板仍将运行／等待队列与已完成托盘分开，不把已完成品算进生产槽。三个配方的原料与制作时长取自正式配置；库存、倒计时和进度只用于展示状态，不是新增生产规则。满仓时成品保留并提供仓库入口，不随意禁用可消耗原料的排产；正式接入仍由现有逻辑判定。

## P1 / P2 边界

按用户要求，**先确认 P0 的视觉方向再扩展**。本轮没有生成新的地形过渡或动画。

现有薄雾、草地、地块边界、树、灌木和三种石头可复用。薄雾源图带菱形底色，后续应先检查连续铺设，再针对裸露直边、转角、疏密和土草过渡补小块透明素材；保持 2:1 投影，地面轴斜率 ±0.5。锁定、选中与缺料提示仍作为 UI 层。清障扬尘、碎屑、木屑和开放闪光属于 P2，待 P1 方向明确后再按短效果规格制作。

## 源文件构建

- `source/build-kit.py`：生成组件 SVG、切片清单，复制并校验原图引用。
- `source/sample.css` / `sample.js`：独立预览布局与状态演示，未接入正式游戏。
- `source/export-artboards.py`：由保留的可见布局记录导出分层 SVG。
- `source/build-gallery.py` / `build-reference-sheet.py`：重建交付预览与已有环境核对表。

沿用项目的 `ZCOOLKuaiLe-Regular.woff2` 标题字体；正文使用系统中文字体。组合 SVG 内嵌现有标题字体供浏览器显示，文字仍可编辑。字体替换后需要复核文本尺寸。
