# 牧场的新邻居 · 装饰与动物素材 v1

基于 main `9df456b`，延续现有暖色描边、奶油色、柔和绿和桃橙色的非像素画风。新增 **4 座可动装饰建筑、6 种动物、72 个独立动物动作帧**。本包只增加美术资源、制作脚本和独立预览，没有修改游戏代码、动物园入口、经济数值或玩家存档。原素材保留。

## 查看效果

在本目录运行 `python3 -m http.server 64247 --bind 127.0.0.1`，打开 `http://127.0.0.1:64247/`。

预览含组合场景、动物、建筑三页，支持暂停、逐帧、脚点锚点、独立阴影及深色底检查。系统设置减少动态时默认暂停。动物帧加载后开始播放，避免第一轮出现空帧。移动端使用两列卡片，完整场景可在第一页查看。

## 新增动物

| 目录 | 物种 | 动作 | 初始建议位移 / 周期 |
| --- | --- | --- | --- |
| `animals/duck` | 奶油鸭 | 交替迈步 | `(-24,+12)` px |
| `animals/rabbit` | 棉尾兔 | 一次完整小跳 | `(-34,+17)` px |
| `animals/goat` | 花斑山羊 | 四足行走 | `(-32,+16)` px |
| `animals/alpaca` | 云朵羊驼 | 四足行走 | `(-30,+15)` px |
| `animals/deer` | 斑点小鹿 | 四足行走 | `(-32,+16)` px |
| `animals/fox` | 蜜桃狐狸 | 四足行走 | `(-32,+16)` px |

每种动物交付 12 个不同透明 PNG 帧、1 张图集、1 个动画 WebP、静态帧联系图和可编辑 ORA。画布 **360×280**，根锚点 **(180,230)**，未裁切，偏移 `(0,0)`；帧率 **12 fps**，每周期 1 秒，帧序 `00–11`，不复制首帧充当末帧。

图集为 **1456×852**：4 列 × 3 行；帧尺寸 360×280，格距 364×284，四周 2px 透明间隔。每帧矩形见各物种 `manifest.json`。`idle.png` 是第 00 帧的静态副本，不算额外绘制的中立状态。

保持同一物种单段统一缩放比例，没有逐帧拉伸到相同包围盒。六种新动物没有旧 layout，因此以实际可见脚掌/蹄尖建立新的地面参照；`visibleFootTips` 标注真实边界像素，`groundSupport` 区分支撑和抬脚。兔子腾空时支撑点为空，地面根锚点仍固定。透明画布底边不作为脚点。

动作在原地完成；场景位移由接入代码负责。上述步幅是接入起点，仍需按最终显示比例校准脚底滑步。当前斜侧朝向可围绕根锚点镜像。ORA 是 12 个可编辑位图帧和独立阴影层，不是四肢拆件的骨骼文件。尚未补吃东西、生产中、完成状态、背面或多方向动作。

## 新增装饰建筑

| 目录 | 装饰 | 动态设计 | 建议占地 |
| --- | --- | --- | --- |
| `decor/watermill` | 溪畔水车小屋 | 转轮 9 秒一圈 | 4×3，侧面给转轮留空间 |
| `decor/gazebo` | 花藤凉亭 | 四面彩旗错相轻摆，3.6 秒 | 3×3 |
| `decor/lily-fountain` | 睡莲喷泉 | 两股细水流与水面涟漪，1.8 秒 | 3×3 |
| `decor/apiary` | 蜂蜜小屋 | 两只蜜蜂绕巢飞行，5.2 秒 | 3×3 |

同一建筑各层均为 **640×640**，对齐锚点 **(320,470)**，偏移 `(0,0)`。独立交付可选阴影、建筑主体、活动层 PNG；活动层 SVG 保留路径和分组。`sources/editable.svg` 内嵌位图，能离线打开；`editable.ora` 可在 Krita / GIMP 中编辑三个位图层。建筑主体是可编辑像素，不宣称为逐根木料拆件。

水车转轮另外交付正圆局部素材和局部枢轴：**先在圆形局部平面旋转，再做斜侧投影**，避免椭圆轮廓跟着旋转变形。凉亭彩旗、水流和涟漪是可编辑矢量小部件；主体保持静止。蜜蜂是独立位图沿路径飞行，本批没有额外翅膀振动帧。动物没有烘焙进建筑。

建筑 `previews/phase-00–11.png` 是检查动作范围的 12 个采样相位，**不是 12 fps 播放图集**。连续动态参考根目录 `motion.mjs` 和 `periodMs`。每座建筑标明地面占地区域、锚点、局部转轴/出水口及源图缩放偏移。运行时动物与建筑仍需按世界深度排序，不允许把动物直接盖在建筑表面。

## 来源、复用与制作

新建筑主体、转轮、蜜蜂，以及六组动物姿势由内置 `image_gen` 生成，参考当前 main 的牛、羊羔、鸡、风车和农舍 PNG。完整提示词及来源记录在 `source/generation-log.json`，12 张生成原图保存在 `source/raw/`。

程序仅负责透明噪点清理、切片、统一缩放、对齐、图集和文件打包。动物步态来自独立绘制的姿势，没有把静态动物左右平移来充当步态。兔子按姿势重排为一次蹬地—腾空—落地的循环。活动 SVG 部件按原有代码素材的配色和描边制作。

`reused/manifest.json` 列出原路径和 SHA-256：复用现有树、灌木、草、花坛、道路组件及三种动物对照图，共 8 项。预览池塘沿用现有完整小场景的代码地形画法。没有复制或改动运行时游戏脚本。

## 重建与检查

需要 Node.js + Sharp、Python + Pillow。先准备依赖，然后从本目录执行：

```sh
node source/build-animals.mjs
node source/build-decor.mjs
python3 source/package.py
node source/verify.mjs
```

Sharp 不在默认模块路径时，可用 `SHARP_MODULE` 指向已安装的 Sharp。详见 `QA.md` 和 `validation.json`。本包不依赖其他未合并的素材 PR。
