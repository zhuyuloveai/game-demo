# 环境补充组件 · 42 项

| 施工与阴影 | 2 | 施工木架、独立接触阴影 |

`components.mjs` 是可复用纯 SVG 组件；`svg/` 为独立资源；`manifest.json` 包含尺寸、地面锚点、旧资源映射和哈希。自然树、灌木、石头复用了已确认场景的形状与配色。

```sh
node environment/build.mjs
node --test environment/components.test.mjs
```

静态服务器预览路径为 `/expansion/`，可以切换木门、土地边界、动物与建筑状态，并逐项查看原图。

## 使用约定

- `environmentSvg(id)` 返回完整 SVG。草地与水面为 128×64，地面中心是 (64,32)；树、门等高物体有各自的画布和地面锚点，见清单。
- `environmentInstance(id,u,v,{unit,origin,scale})` 返回 `{markup,depth}`。`unit` 控制地图投影，`scale` 只改变素材大小，落地点保持固定。高物体要与角色一起按 depth 排序。
- `waterConnections(cells)` 根据缺少邻居的方向计算岸线。`waterPatchMarkup(cells,options)` 支持不规则水域、洞和独立水格，内部边不绘岸线；渲染函数支持全部 16 种边界组合，10 个导出文件保持旧资源清单粒度。
- `gateGeometry(axis,state)` 的铰链、门柱和地面中心在开关前后保持一致；`passable` 是接入提示，实际通行逻辑由游戏决定。
- 四向滚屏箭头表示屏幕方向；水岸 N/E/S/W 表示斜向逻辑网格方向，与上一批道路组件一致。
- 边界、占地和雾是局部覆盖层，独立于地面。界面文字、价格和进度由游戏叠加。

本批提供素材、接口和独立预览；正式地图中的新环境资源替换另行接入。
