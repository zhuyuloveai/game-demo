# 农场美术空间适配验收 · 2026-10-26

在 `71c80aa` 的素材与动物状态接入基础上，处理系统审查发现的朝向、比例、落点、遮挡、连接和信息覆盖问题。沿用现有贴纸美术，成熟胡萝卜单独修正原稿，其余素材通过空间标注、原生 SVG 组件和渲染规则适配。

## 本轮修改

- 115 张 PNG 增加独立显示宽度、根部/脚底锚点、地面连接点。建筑与逻辑占地解耦，作物各状态共用地面落点，自然树木/灌木/石头重新校准尺度。
- 五类栏舍拆为地面、后景棚舍、独立动物、前景围栏；围栏留出与操作门相符的缺口，购买预览也显示完整院子。动物容量、槽位编号和生产规则不变。
- 布置时实际反射图片，同时反射 alpha 命中轮廓和出货点。新 UI 只提供素材支持的两个正面方向。旧存档的背向仍可读取，用户主动恢复正面后才改变。
- 桥、拱门、庆典横幅四件复合装饰使用同源画布前后裁剪和层级；花篱笆增加 16 个邻接组件，可组成端头、直线、转角、T 形和十字连接。
- 生长计时仅在选中后显示，成熟/复苏状态缩为小标记；机器成品合并显示数量，保留 44×44 屏幕像素的领取热区。
- 85 个库存物品 SVG 调整为细暖棕描边。成熟胡萝卜改为只露根冠的在地状态，更新原稿、生成记录、状态缩放、运行时派生图及校验信息。
