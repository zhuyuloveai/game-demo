# 建筑状态标记 · 8 项

以奶油色小纸牌和浅暖描边绘制，可叠在各种建筑上方。全部为独立透明 SVG，不把数字进度或时间写入图片。

- 施工中：木锤和木板。
- 加工中：沙漏。
- 已完工：绿色对勾。
- 仓位已满：装满的木货箱。
- 四级熟练度：种子、嫩芽、四叶小枝、花朵，对应原项目 `mastery-0` 至 `mastery-3`。

全部画布为 64×76，底部指针锚点为 (32,72)。`buildingBadgeMarkup(id,{x,y,size})` 将指针尖对齐指定位置，独立调整显示大小。建议置于建筑上方，避免遮挡建筑主体与点击区域。状态名、读屏标签和数值信息由使用方提供。

`/expansion/` 的建筑标签页展示 64、32、24 px 三档缩放；组合场景可以切换全部八个状态。源文件、旧资源映射和哈希见 `manifest.json`。

```sh
node building-states/build.mjs
node --test environment/components.test.mjs
```

本批完成状态图形与叠加接口；正式游戏的队列、熟练度与状态选择尚未连接到这些新标记。
