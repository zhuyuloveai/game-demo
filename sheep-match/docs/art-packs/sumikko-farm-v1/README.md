# 羊羊牧场 · 基础素材与植物、地形补充包

以用户提供的《角落生物农场》截图为主要风格参考，采用浅暖色描边、圆润比例、粉彩配色和俯视三分之四角度。每种素材独立保存为带透明通道的 PNG。

农舍、鸡舍和绵羊沿用前一版已生成素材，其余 60 种为本批生成。苹果树和小麦在整套检查时重新生成，使植物的描边和明暗更协调。作物使用成熟形态，果树与浆果使用结果形态，动物使用单个静止姿势。

## 查看与使用

以本目录为工作目录，先生成下载包，再启动静态服务（需要 Python 3 标准库）：

```sh
python3 package_assets.py
python3 -m http.server 64233 --bind 127.0.0.1
```

浏览器访问 `http://127.0.0.1:64233/`。预览页支持分类、草地/奶油/棋盘底色切换、放大和原图下载。`assets.zip` 是可重新生成的下载包，已加入本目录的 Git 忽略规则。

完整小场景位于 [`scene/`](scene/README.md)，同一静态服务下访问 `/scene/`。它将现有素材组合成房舍、菜地、动物围场和果园，并补齐 SVG 道路、田埂、连续栅栏和环境植被，支持拖动缩放及布局线查看。

后续资源缺口和建议批次见 [`ASSET-GAPS.md`](ASSET-GAPS.md)。本次已补齐 **42 张植物状态 PNG**，并整理 **35 个道路/围栏/田地 SVG 组件**。植物阶段对照见 [`plant-states/`](plant-states/README.md)，地形拼接预览见 [`terrain/`](terrain/README.md)。当前共有 105 张独立素材 PNG（63 基础 + 42 状态）和 35 个地形 SVG。

`manifest.json` 对应每张图片的中文名称、项目素材 ID、相对路径、复用来源或生成记录，以及完整提示词。`generation/` 保存本批新生成素材的来源记录。`qa/report.json` 记录尺寸、透明通道范围、主体边界和文件哈希，`qa/*.jpg` 是按分类排版的检查图。

生成记录中的原始绝对路径仅用于溯源；预览和打包均使用本目录的相对路径。未采用的草稿和风格参考截图保留在制作工作区，不包含在此目录内。

这些文件保留生成原始分辨率和透明留边，没有做运行时裁切、图集或压缩。植物补充包已提供统一底部落地点与相对尺度的展示元数据。接入游戏时可参考 `opaqueBounds` 设定占地尺寸和底部锚点，再按实际显示大小导出运行时资源。

## 本批范围

基础包仍为 63 种静态外观，`manifest.json` 保持原有清单。新增植物状态和地形各有独立清单；动物动作帧、皮肤和界面图标仍待制作。本目录是独立素材预览，不会自动替换游戏里的素材。

`assets.zip` 包含 63 张基础 PNG、42 张植物状态 PNG、35 个地形 SVG 及源码、三种预览页、完整小场景及导出图、资源缺口清单、生成记录和检查图；草稿和风格参考截图不放入交付包。
