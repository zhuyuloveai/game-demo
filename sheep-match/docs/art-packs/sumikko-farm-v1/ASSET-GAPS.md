## 本批接入时需要处理

- 根据 `legacyPath` 替换环境与建筑标记，复用现有斜向投影；水岸按相邻水格选择，木门开关与通行逻辑同步。
- 将动物 `producing`、`ready` 映射到现有状态，依据主体边界与底部锚点保持落地位置；按显示尺寸导出运行资源，减少原始 PNG 的下载与解码开销。
- 建筑标记使用独立尺寸和顶部提示位置；熟练度数值、生产倒计时和产物由游戏 UI 叠加。
- 核对旋转方向与占地；单侧入口、文字或机械结构不直接假定镜像等价。
- 验收播种 → 生长 → 收获 → 喂养 → 收取 → 加工 → 出售，检查切换时是否跳回旧风格。本次独立预览不等同于正式玩法验收。
