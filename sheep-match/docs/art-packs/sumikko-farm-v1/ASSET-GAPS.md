# 小牧场新风格资源覆盖与缺口

核对日期：2026-10-26。范围为当前种地牧场；四季首页、消除关卡、剧情 CG 和其他季节玩法不计入本次替换范围。

基准：正式资源清单 `sheep-match/assets/farm/manifest.json`、运行时 `sheep-match/farm-scene-world.mjs`、本素材包 `manifest.json` 和 `scene/scene.js`。这里的“缺”指新风格尚未覆盖；正式游戏已存在相应的旧资源。

## 已完成

- 63 张基础透明 PNG：22 种建筑/设施、11 种成熟作物、5 种结果果树/浆果、5 种动物静态姿态、20 种装饰。
- 独立小场景使用其中 26 种、57 个实例，验证了素材组合、尺度和落地锚点。
- 新增 SVG 场景画法：草地与草花点缀、连通道路、田块与田埂、分段围栏、普通树、灌木、石头、池塘与水波。
- 小场景支持深度排序、拖动缩放、布局线、轻微动态和完整 PNG 导出。

这些环境元素目前由 `scene/scene.js` 绘制，属于场景原型；尚未拆成正式游戏可调用的地形资源及邻接规则。新 PNG 也尚未替换游戏运行时的旧 SVG。

## 地形的具体范围

正式清单中的 77 项可以按下面的粒度整理，主要适合继续使用 SVG/程序绘制：

| 组 | 数量 | 内容与当前小场景的差距 |
| --- | ---: | --- |
| 草地、点缀 | 9 | 草地 3、草花点缀 6；已有场景画法，需要拆成可复用底纹/组件 |
| 田地 | 3 | 空田、播种、施肥；当前只有静态田格与成熟植物组合 |
| 道路 | 16 | 按四邻接编码的端头、直线、转角、T 形、十字等；当前是固定连通路径 |
| 围栏 | 16 | 连续连接与交角；当前已有分段绘制和深度排序，需要接入邻接规则 |
| 水面与水岸 | 10 | 水面、四边、四角、涟漪；当前只有一处固定池塘 |
| 门 | 4 | 两种方向 × 开/关；当前有静态花拱门，没有可开关门组件 |
| 土地边界 | 4 | 已拥有、可拓展、未解锁、迷雾 |
| 放置反馈 | 4 | 普通、可放、冲突、入口占地 |
| 滚屏指示 | 4 | 四方向边缘指示 |
| 自然障碍 | 5 | 树、灌木、3 种石头；当前有树/灌木和一种石头画法 |
| 施工/阴影 | 2 | 施工架、落地阴影；当前已在场景内实现统一接触阴影 |
| 合计 | **77** | 这是资源条目数，不需要全部生成成独立 PNG |

正式地图当前把每条路都渲染为 `terrain/road-f.svg`。替换时还要根据邻居选择道路连接形状，单换图片不会自动得到小场景里的连通效果。

## 建议下一批

1. **优先补 42 张植物状态图**：22 张作物阶段 + 20 张果树/浆果阶段。以现有成熟素材为参照，保持树冠、茎叶、轮廓和落地锚点一致。
2. **把场景环境整理成可复用地形组件**：先道路 16、围栏 16、田地 3，再草地/自然物、水岸和边界。复用小场景已经确认的画法。
3. **补动物的最小状态表达**：5 种动物各补生产中、可收取，共 10 种状态设计。可以选择姿态加状态覆盖层；定稿后再决定独立文件数。现有运行时只读取正面 idle/producing/ready 的第 0 帧，完整 225 帧动画留到后续独立批次。
4. **统一经济界面图标**：64 商品 + 21 材料/货币 + 35 操作符号，共 120 个图标，先做高频作物、饲料、鸡蛋牛奶和收获工具验证小尺寸可读性。
5. **再做生产动画、装饰分层、皮肤和成就资源**。

42 张植物状态图是可以直接启动的明确生成数量。地形采用组件方式，动物采用状态/动画规格，分别计数，不合并成一个容易误解的“还差多少张”。

## 接入时必须一起处理

- 把原运行时的屏幕方格定位改成与新素材一致的斜向投影，统一建筑尺寸、落地锚点和前后遮挡。
- 核对旋转后的图像朝向与占地；有单侧入口、文字或机械结构的物件不能直接假定镜像等价。
- 用 `opaqueBounds` 和确认过的场景比例整理运行时锚点；按实际显示尺寸导出资源，减少原分辨率 PNG 的下载与解码开销。
- 验收一个完整循环：播种 → 生长 → 收获 → 喂养 → 收取 → 加工 → 出售，检查过程中有没有跳回旧风格。
