# 羊羔棚分层交付

基于 main `7925a5b`，已完成本轮素材优化。原文件全部保留，未修改游戏代码。开放入口，去掉前挡栏、侧栏与外部杂物。

## 文件

- `lamb-empty.ora` / `lamb-full.ora`：可编辑分层源；满栏的 5 只动物逐只分层。
- `lamb-empty-source.svg` / `lamb-full-source.svg`：可编辑分组组合源，和 `sources/` 一起保留。
- `layers/`：5 个设施层，以及仅作参考的动物/阴影层。统一透明画布 **1200×1000**，锚点 **[600,590]**，偏移 **[0,0]**，不裁切。
- `animals/`：3 种状态与独立阴影。统一 **360×280**，身体宽 **200 px**，接地锚点 **[180,230]**。
- `previews/empty.png` / `full.png` / `spatial-guide.png`：空栏、满栏与空间标注。
- `layout.json`：入口、地面、建筑投影、可站立外轮廓及排除区、前栏遮挡边界、源图变换、动物身体框与真实接触点。
- `qa-report.json`：逐状态与所有满栏位置的检查。

## 接地点

身体区域按实际形体选择，蹄/趾/腹部接点逐张观察并沿 alpha 下沿核对；不使用透明画布底部中心。支持点可能有投影深度差，清单中保留多个实际接触点。原动物图只做等比归一和坐标调整。
