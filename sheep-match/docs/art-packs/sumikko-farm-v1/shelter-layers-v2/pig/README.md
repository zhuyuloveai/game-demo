基于 main `7925a5b`，已完成本轮素材优化。原文件全部保留，未修改游戏代码。保留贴墙饲槽，去掉右后旧围栏，错位摆放避免遮脸。

## 文件

- `pig-empty.ora` / `pig-full.ora`：可编辑分层源；满栏的 5 只动物逐只分层。
- `pig-empty-source.svg` / `pig-full-source.svg`：可编辑分组组合源，和 `sources/` 一起保留。
- `layers/`：5 个设施层，以及仅作参考的动物/阴影层。统一透明画布 **1200×1000**，锚点 **[600,590]**，偏移 **[0,0]**，不裁切。
- `animals/`：3 种状态与独立阴影。统一 **360×280**，身体宽 **224 px**，接地锚点 **[180,230]**。
- `previews/empty.png` / `full.png` / `spatial-guide.png`：空栏、满栏与空间标注。
- `layout.json`：入口、地面、建筑投影、可站立外轮廓及排除区、前栏遮挡边界、源图变换、动物身体框与真实接触点。
- `qa-report.json`：逐状态与所有满栏位置的检查。
