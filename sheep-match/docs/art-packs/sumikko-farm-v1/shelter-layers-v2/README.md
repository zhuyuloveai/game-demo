# 动物栏舍透明分层素材 v2

基于 main `7925a5b` 的局部美术修正。牛棚样板获准继续后，已完成牛棚、猪圈、绵羊棚、羊羔棚与鸡舍五种设施。**仅新增本目录的素材、源文件、标注和预览工具；不修改原素材、游戏代码、运行时清单、存档或经济规则。**

## 交付总览

| 设施 | 满栏数量 | 本轮处理 |
| --- | --- | --- |
| 牛棚 | 5 | 去掉旧外栏和前半门，保留蓝屋顶、墙体、牛奶标牌及侧饲草位 |
| 猪圈 | 5 | 去掉右后旧栏杆；保留开放入口与贴墙饲槽，调整满栏错位摆放 |
| 绵羊棚 | 5 | 保留屋顶、标牌和承重柱，移除旧围栏与前饲草架，院地延续到棚下 |
| 羊羔棚 | 5 | 去掉前挡栏、侧栏、外部花丛与独立饲槽，保留黄色屋顶、墙面、开口及内部草床 |
| 鸡舍 | 6 | 原图逐字节复用，保留小屋和坡道；校准坡道末端与院地、阴影的衔接 |

五种设施均适配 **4×4 格**，未建议扩大占地。容量组合合计 **26 只独立动物**；三态全部复用，合计 **15 个状态**。没有把动物、小鸡蛋、饲料、时钟或其他 UI 画进建筑图。

每种设施都包含 5 个设施图层：院地、建筑阴影、后栏/远侧栏、建筑主体、前栏/近侧栏。前后栏来自同一圈栏杆的共享源图与裁分坐标，组合时不出现两圈栏杆。鸡舍主体含既有坡道，不进行无理由重画。

## 可编辑文件与透明导出

- `index.html`：五种设施总览，进入各页可开关图层、切换状态、检查标注。
- `<设施>/<设施>-empty.ora`、`<设施>/<设施>-full.ora`：10 个可编辑 OpenRaster 源文件。满栏文件中的每只动物都是独立图层，供摆放参考。
- `<设施>/<设施>-empty-source.svg`、`<设施>/<设施>-full-source.svg`：分组 SVG 组合源。新增四种设施以相对路径引用本目录原图，移动时须带上 `sources/`；PNG 本身是位图，不宣称逐路径可编辑。
- `<设施>/layers/*.png`：统一 1200×1000 透明画布，偏移 `[0,0]`，公共地面锚点 `[600,590]`，不裁切。
- `<设施>/animals/*.png`：统一 360×280，身体图和阴影分别交付，落地参考锚点 `[180,230]`。
- `<设施>/previews/empty.png`、`full.png`、`spatial-guide.png`：空栏、满栏、空间标注。
- `<设施>/sources/`：原建筑、原动物三态与编辑后源图，可逐项对照，原项目文件不覆盖。

**86 张透明 PNG 导出**包含 25 张设施层、15 张动物状态、15 张动物阴影、26 张满栏参考动物层和 5 张满栏参考阴影层。组合预览不计入这 86 张。

## 空间和尺度约定

地面四角 `[600,340] [1100,590] [600,840] [100,590]`；单格投影轴 `[125,62.5]` 与 `[-125,62.5]`，斜率 ±0.5。草边和屋檐可以少量视觉外扩，逻辑占地不变。

每种设施的 `layout.json` 记录入口、地面投影、可站立区域、建筑/坡道排除区、前栏遮挡边界、源图变换和各动物的真实接地点。可站立区域按 `standingRegion` 外轮廓减去 `standingExclusions` 理解；这些区域是美术交接数据，不写入游戏。

动物身体区域根据实际轮廓人工选择，排除角、尾巴或突出耳朵对尺寸判断的干扰；接触点沿对应蹄、趾或腹部的实际 alpha 下沿核对。三态按身体宽度等比归一，不用透明画布尺寸决定比例，也不把画布底部中心当脚点。趴卧的高度变化保留，作为姿态差异。

同种动物身体宽度完全一致，横向身体中心差异最大 **2.92 px**（交付画布尺度，换算到 192 px 宽的 4×4 地面约 0.56 px）。源坐标、缩放、偏移、身体框和多接触点均在清单中。

## 验证证据

`qa-report.json`：五种设施全部通过，检查 15 个状态、78 组“满栏位置 × 状态”，所有接触点都落在 4×4 地面和可站立区内，并避开建筑/坡道排除区；20 份原建筑/动物副本 SHA-256 与原文件一致，鸡舍编辑源也与原图一致。另验证 86 个透明导出的画布、alpha、身体宽度与接触边界。

10 个 ORA 包的层数、压缩包完整性和合成预览已核对。空栏/满栏组合进行了视觉检查，猪和绵羊的满栏布局调整为错位分布，避免前排挡住后排面部。浏览器验证记录另见 `browser-verification.md`。

这些验收只确认美术组合与文件交付；点击区域、游戏站位、收获交互和代码接入不在本轮范围内。没有部署线上。

## 构建

需要 Node.js + sharp，以及 Python 3 标准库。

```sh
node cow/build-layers.cjs
node build-additions.cjs
python3 package-all.py
node verify-all.cjs
python3 build-preview-pages.py
```

使用内置 image_gen 局部编辑，未走 API/CLI。牛棚和共享院地/围栏的提示词见 `cow/generation-prompts.md`；猪、绵羊、羊羔的准确提示词与生成源路径见 `generation-additions.json`。鸡舍和 15 个动物状态无生成步骤。
