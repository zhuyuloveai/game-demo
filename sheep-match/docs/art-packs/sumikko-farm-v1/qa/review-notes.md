# 视觉检查记录

- 建筑设施在同一草地底色上检查造型、配色、轮廓和整体视角。
- 乳品坊、糖坊、织布机因低透明度像素比例较高，额外在浏览器的棋盘底上放大检查；没有可见底色框，主体和空隙显示正常。
- 南瓜生成了三版候选。生成工具的内联预览出现光晕，但保存的 PNG 合成到草地背景后没有该光晕。最终采用第二版的双南瓜植株，轮廓和叶片更简洁，也比单个南瓜更适合表示成熟田间作物。三版原文件和提示词保留在制作工作区的 `drafts/`，本目录只包含选定版本。
- 个别生成 PNG 的最大 alpha 为 254，与完全不透明仅差 1/255。格式检查分别验证背景存在 alpha 0、主体存在 alpha ≥254；不以最大 alpha 必须等于 255 作为透明底是否有效的判断。
- 检查图是从原 PNG 合成的只读预览；交付 PNG 未经过脚本修改像素。
- 旧版小麦和苹果树的描边、明暗偏重，已重生成较轻的版本。最终沿用 3 张旧素材、新生成 60 张。
- 最终五组检查图已逐组查看：22 种建筑设施、11 种作物、5 种果树浆果、5 种动物、20 种装饰。检查了形态是否可辨认、轮廓是否裁断、同组配色是否协调。
- 木栅栏另在浏览器棋盘底上放大检查，两根横栏之间的空隙和主体外侧均显示透明。
