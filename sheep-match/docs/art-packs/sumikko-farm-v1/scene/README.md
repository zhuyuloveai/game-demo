# 完整小牧场场景 / 01

将首批素材拼成可浏览的独立小场景，用于检查布局密度、比例、落地锚点和前后遮挡。房舍院落、20 格菜地、鸡舍围场、小动物围场、前景果树和池塘组成一个完整画面。

## 本地查看

在 `sumikko-farm-v1` 素材包目录启动静态服务：

```sh
python3 -m http.server 64234 --bind 127.0.0.1
```

访问 `http://127.0.0.1:64234/scene/`。支持拖动、滚轮/双指缩放、全景/近看、布局线、暂停动态和点击动物。右上角可保存 1600×1030 的完整场景 PNG。键盘可使用方向键移动、加减号缩放、0 回到全景。

## 绘制方式

- 直接引用上级素材包的透明 PNG，没有复制或改写原图。
- `assets.json` 从素材包的清单和 QA 主体边界提取。使用嵌套 SVG 的 `viewBox` 统一透明留白，不对 PNG 作破坏性裁剪。
- 地面采用 2:1 正交斜向网格。道路连成一个网络；田地、围栏、树丛、普通树、石头和池塘用 SVG 绘制。
- 建筑、动物和分段围栏按落地深度排序；植物轻摆、动物呼吸、蝴蝶和水波提供轻微动态。
- 这是静态美术与布局原型。动物点击只用于展示反馈，不读写正式游戏进度，也不包含种收、生产等游戏逻辑。

道路、田地和围栏已复用 `../terrain/components.mjs`；普通树、灌木、池塘仍保留场景画法。

植物补充包可通过 `?plants=sprout`（幼苗/幼株）、`?plants=grown`（生长中）、`?plants=mixed`（混合阶段）显示；共用原布局、落地锚点和成熟图基准尺度。默认仍为成熟植物。
