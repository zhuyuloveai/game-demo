# 环境、动物与建筑标记组合预览

本页汇总本批 **42 项环境 SVG＋10 张动物状态 PNG＋8 个建筑状态 SVG**，并复用已有房屋、道路、围栏、田地和 5 张动物日常图。

从素材包根目录启动静态服务器：

```sh
python3 -m http.server 64234 --bind 127.0.0.1
```

访问 `/expansion/`。上方组合场景可切换动物状态、木门开关、建筑标记和土地边界；支持导出 1600×960 PNG。下方三组图鉴支持放大、透明底检查、下载原图，建筑标记同时展示 64/32/24 px。

场景使用各组件的公共接口、地面锚点与深度顺序。图鉴中的日常动物是上下文参考，不计入本批新增 10 张。此页不读写游戏存档。
