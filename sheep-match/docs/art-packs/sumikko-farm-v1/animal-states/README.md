# 动物状态补充包 · 10 张

小鸡、奶牛、小猪、绵羊、羔羊各增加 `producing`（生产中）和 `ready`（可收取）两张透明 PNG。复用 5 张已有 `idle` 日常图，清单共 15 个状态。

采用当前已确认动物作为身份与风格参考，通过 Codex 内置 imagegen 逐张生成。保留奶油/浅桃色、暖色轮廓、点眼睛、身体比例，以及奶牛斑纹、羔羊卷毛等识别特征。生产中用低伏休息姿态；可收取用抬头、站起、翅膀轻扬或更蓬松的羊毛表达。图中没有烘焙进产物、气泡或计时符号，游戏可独立叠加提示。

`jobs.json` 是本批完整提示词；`generation/*.json` 保存实际提示词、参考图路径和内置工具原始输出。没有使用 CLI/API key 生成方式。PNG 保留生成原始分辨率与 alpha，工具原文件也保留。

`manifest.json` 提供 `opaqueBounds`、原图底部中心 `anchor`、相对宽度 `displayScale`、项目 ID、状态、来源与哈希。预览使用 SVG viewBox 对齐主体，换姿态时保持同一个地面落点。绵羊可收取状态的显示宽度为日常的 1.08 倍。

```sh
# 需要 Pillow；不修改源 PNG，只生成清单、QA 报告与检查拼图
python3 animal-states/build_manifest.py
```

`qa/states.jpg` 按日常 / 生产中 / 可收取展示全部五种动物，`qa/report.json` 校验透明通道、唯一哈希与原始输出一致性。统一交互预览位于 `/expansion/`。

这是静态状态补充，完整行走、进食、收取动画和多朝向帧仍为后续批次。本批新状态尚未替换正式游戏中的日常动物图。
