# 成长布局与斜俯视场景

## 运行时接入

- `farm-growth-layouts.mjs`：基于实际拥有量的五个里程碑、稳定槽位、碰撞时合法备用位置、完整草稿预览。
- `farm-runtime-terrain.mjs`：已有道路与木围栏的四邻接贴图，以及空田/播种/施肥田地。上游已是2:1素材，不再重复投影。
- `farm-world-geometry.mjs`：2:1 投影及逆映射、地面多边形、直立精灵落点、深度和全景相机。
- `farm-runtime-art.mjs` / metadata：状态敏感 PNG 映射、裁剪边界、透明命中采样。原素材和可复现派生说明见 `farm-runtime-art.md`。
- `farm-scene-world.mjs`：正式 host/store 渲染；购买、采集、布局提交仍经 durable store，未另建游戏经济。

## 成长与兼容性

新农场采用蓝图；新购置物件优先推荐稳定槽位，可改成手动位置。碰撞时仅为新增物件找合法落点，不挪已有物件。阶段按已有田地、工坊、动物种类和果树种类判断；不是固定每N级换地图，也不赠送设施。

旧存档加载不重排、不写入新增 schema 字段。布置模式中的「预览成长布局」生成只读的位置与免费道路预览；撤销预览恢复原手动草稿，取消不写入，明确点击「应用推荐布局与道路」才经签名校验原子提交。预览不会消耗ID或资源。保留全部实体ID、库存、作物时间、施工/生产队列、动物状态。固定小屋/自然障碍仍不可移动。64×64地图、初始16..48边界、22级8×8付费扩地及材料扣除未改变。

测试覆盖48田、13工坊、12个可拥有栏舍、全部11作物与5果植；新增素材覆盖11作物的幼苗/成长/成熟和5果植的幼株/成长/成熟/待救活/最终枯萎状态；特殊皮肤、自然障碍、动物动作和不存在的朝向按说明保留旧实现。不会把没有购买的对象展示成已拥有。

## 遮挡与操作

- 正常可见成熟田单击收获；拖地图、双指缩放不会作为普通收获点击。
- 农田透视是明确开关，仅针对成熟作物田：田地不透明并描边，前景相交物件淡化，命中先路由到成熟田。结束/取消恢复正常。
- 地面占地、精灵透明区域及互动目标分开计算；同深度时命中顺序与DOM绘制顺序一致。
- PNG透明命中使用64×64采样mask，不宣称逐像素精确。精灵仍是单个固定朝向，编辑旋转改变逻辑占地/门口，不能生成不存在的美术朝向。
- 机器成品、动物工具操作及原减少动态开关保留；PNG动物为静态姿势，不虚构多帧动画。
- 全景缩放保留原`.75..1.75`相机约束。窄屏高级农场仍需拖图，不强制缩成难点选的小图。新农场及明确采用推荐布局时补齐连接道路，使用已有商店道路0金币规则；推荐位置原样确认购买也可延伸免费道路，手动移动/旋转后的购买不自动补路。道路每次最多新增256格，遵守正式4096格上限与土地边界，重复采用不重复添加；保留自定义道路和固定障碍。付费装饰不自动购买。

## QA方式

从仓库根目录运行：

```sh
node --test sheep-match/tests/*.test.mjs
python3 sheep-match/deploy/package-release.py /tmp/new-farm-local-package
```

发布打包白名单包含新模块和105张运行PNG与35个道路/围栏/田地SVG，排除tests/docs/tools。打包脚本仅生成本地文件，不部署。

`tests/farm-growth-browser.html?stage=1` 至 `stage=5` 为隔离QA入口，挂载正式host和store。测试档的等级/资金仅用于覆盖内容，不代表自然成长耗时或经济平衡。`?ripe=1&occluded=1` 是合法但仓库遮住成熟田的旧布局场景，`?resume=1` 读取该隔离QA命名空间以测刷新；不读写正式玩家存档。
