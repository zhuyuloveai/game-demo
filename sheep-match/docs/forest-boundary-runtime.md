# 未开发林地：运行时呈现

本地实现基于现有 natural-tree / natural-bush / accent 与自然障碍资源，不新增美术或存档字段。

- `farm-forest-boundary.mjs` 纯派生模型只读取 openedLand。装饰由地块 ID 和序号固定散布，真实清障预览使用现有 expandLand 的 3 石堆 + 1 树身份与坐标。
- 开放区域只绘制共同外轮廓，不绘制已开地块之间的缝。常态林地无锁图标；进入开垦页时才显示可开垦提示，选中地块轻淡化林冠。
- 真实实体和装饰互不混淆：装饰不进入存档、命中或工具消耗；解锁后真实障碍接替预览，装饰短暂淡退。已经开放并清过的地不会重新长障碍。
- 林冠覆盖经营对象时降低不透明度；所有林地派生图片 pointer-events:none，正式 hitWorld 仍只匹配真实实体和 P12 地块。工具不会误清装饰。
- 使用量化投影视口裁剪，默认最多 480 装饰 + 192 障碍预览；视口变化只裁剪，不改树的位置。淡退节点上限 24、700ms 清理，退出清定时器，减少动态模式关闭淡退。
- 原扩地等级、共边限制、材料消耗、每块障碍数量及保存格式保持不变。选中已清地块显示已开放，不误称待清理。

验证：纯模型稳定性、与核心真实障碍深等、连续邻块无内部边、旧开放地清理后不再生、视口裁剪/预算、全开放无幽灵林地和生产包依赖覆盖。真实浏览器验收另记录，不以纯测试替代视觉质量。
