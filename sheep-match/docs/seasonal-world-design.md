# 羊羊牧场四季小世界设计方案

> 本文保留为四季小世界的历史概览。核心农场以[完整农场设计方案 v0.4](farm-design/README.md)为准；旧文与新版冲突处采用新版。本次仅提交设计，不代表玩法已实现。


状态：设计基线，尚未实现。更新日期：2026-10-24。

保留三消闯关主线，把四季主页扩展成可以进入、操作和留下变化的小世界：春天种菜，夏天出海钓鱼，秋天进山采山货，冬天回暖屋团聚。全年共享厨房，把各季收获变成料理、招待和收藏。

已讨论认可的是四季题材与整体循环。下文的一轮操作、制作顺序和实现边界是建议方案；时长、产量、稀有概率和成长节奏仍待确定，不代表已逐项确认。

## 现有基础与新增范围

现有版本已有四季主页、每季六组布置、三消主线、牧场笔记和本机存档。每四关主线首通获得一组布置，第24、48、72关开启下一季，第96关开启下一年，旧年份可以回看。

本方案新增的是进入场景后的实际玩法、共享物品和厨房，不把现有主页贴纸或剧情播放当作已经具备这些功能。现有六组奖励可以承接渐进建设，但具体哪些组开放入口、工具或装饰，需要单独安排。

- 三消仍是主线与主要解锁来源，经营不成为继续三消的前置条件。
- 已解锁的四季可随时返回，不绑定现实日期，也不要求等到对应季节。
- 不做体力限制、作物过期、漏登录损失或定时领取惩罚。
- 每个场景都要有选择、操作和反馈，不能只是点击领取礼包。
- 本轮不引入商业化、账号、联机或新服务器。

## 主页与场景入口

四季主页继续承担浏览、收藏和继续闯关。将场景中可识别的建筑或物件作为入口，点击后进入独立场景，不挤占原来的「继续闯关」。

| 季节 | 主页入口 | 进入后做什么 | 留在世界里的变化 |
| --- | --- | --- | --- |
| 春日花溪 | 小农舍与门前菜圃 | 播种、照料、收获、布置 | 菜地成长与农场装饰 |
| 夏日海风 | 码头边的小帆船 | 选航点、航行、钓鱼、拾贝 | 航点发现与海边收藏 |
| 秋日果园 | 通往山林的小径或采山篮 | 搜索山货、寻找珍贵蘑菇 | 山货图鉴与林间收藏 |
| 冬日雪乡 | 亮灯的暖屋 | 摆家具、迎接小羊、准备团聚 | 屋内陈设与相聚纪念 |

入口保持轻微动态或点按高亮，并提供可读名称；锁定时说明条件，不让用户猜哪里可点。场景内始终有明确返回按钮，回到原季节和原年份，不重开正在进行的三消牌局。

厨房是全年共享空间。建议在已解锁的小屋场景及公共导航提供同一个厨房入口，四季使用同一份食材和料理库存，而不是各建一套厨房。

## 春天 花溪迷你农场

春季小屋改造成小农舍与可进入的菜圃。保留花溪、粉顶小屋和手绘贴纸风格，重点让玩家看到自己的照料带来变化。

建议的一轮操作：

1. 点击主页农舍，进入菜地，选一块空地和已有种子。
2. 播种后点击浇水，观察幼苗变化；生长推进规则在节奏确认后确定。
3. 成熟时点击收获，作物进入共享库存，土地回到可种植状态。
4. 将收获带到厨房，或移动已获得的花篱、盆栽等装饰。
5. 返回主页，保留土地与布置状态，可直接继续三消。

首次体验建议提供足够完成一轮的种子与操作机会，避免开场先等待。成长不依赖必须准点上线；成熟后一直保留。首版用少量作物与固定摆放位置验证手感，不先做大地图和任意建造。

## 夏天 海湾航行与钓鱼

从小帆船进入航点地图，先做可选择目的地的短航程，不做复杂自由航行、船只战斗或航海贸易。

建议的一轮操作：

1. 在码头选择一个已开放航点，例如近岸浅湾或贝壳小岛。
2. 播放简短航行动画，可返回或跳过，不让长动画成为重复负担。
3. 到达后选钓点抛竿，通过清晰的浮漂反馈完成收线；难度和容错待试玩确定。
4. 在岸边点击可搜索位置拾贝，将鱼和贝壳带回。
5. 鱼可做料理，特色贝壳进入收藏或海边布置，返回原码头。

不同航点应有不同视觉与发现，避免只是同一张抽奖按钮换背景。初期航点数量和渔获种类保持小规模，先验证「出发、操作、带回收获」是否顺畅。

## 秋天 进山采山货

秋季扩展的重点是采山货和发现珍贵蘑菇。原有秋日果园作为出发地，山径连接树根、倒木、落叶堆等短路线探索节点。

建议的一轮操作：

1. 点击山径进入采山场景，在分岔处选择一条短路线。
2. 观察树根、倒木和落叶边缘的线索，点击拨开落叶或检查倒木。
3. 获得普通山货，例如栗子、浆果或设定中的常见蘑菇。
4. 偶尔发现造型鲜明的珍贵蘑菇，出现独立发现反馈并点亮图鉴。
5. 带着采山篮回家，选择做料理或保留收藏。

珍贵发现的乐趣来自观察与探索，不把每一步都做成纯概率领奖。稀有出现概率、保底方式及路线刷新规则待定；普通收获也应有稳定用途，避免没有稀有物就等于白跑。

蘑菇采用架空名称和造型，不能提供或暗示现实食用识别。料理使用的是游戏设定食材；收藏展示也不承担现实采食指导。

## 冬天 雪乡暖屋

进入有壁炉的暖屋，围绕家具布置、来访小羊和共享料理建立温暖的收尾体验。

建议的一轮操作：

1. 点击亮灯木屋进入室内，选择地毯、椅子或桌面装饰的位置。
2. 与来访小羊互动，得知一次轻量招待主题或喜欢的料理类型。
3. 从共享厨房取出料理摆上桌，确认招待后消耗对应数量。
4. 观看简短团聚反馈，留下收藏纪念或获得新的装饰选择。
5. 随时离开暖屋；来访不设置必须赶上或错过受罚的倒计时。

首版不做复杂人物关系数值或排班经营。冬天的差异是把全年收获用在一个可布置、可招待的小家，而不是再次增加采集玩法。

## 共享物品与厨房循环

基本循环为：三消推进与解锁 → 场景操作 → 食材或收藏 → 厨房料理 → 野餐、送礼、招待 → 收藏与装饰反馈。料理不增加三消必需战力，也不作为通关门票。

| 物品类别 | 来源示例 | 主要用途 | 需要避免的混淆 |
| --- | --- | --- | --- |
| 种子与普通食材 | 春季种植、夏季渔获、秋季山货 | 种植或制作料理 | 种子与收获物使用不同图标 |
| 珍稀发现 | 珍贵蘑菇、特色贝壳 | 图鉴、收藏；是否可烹饪待定 | 首次收藏记录不能因消耗而消失 |
| 成品料理 | 共享厨房配方 | 野餐、送礼、暖屋招待 | 制作成功才扣食材，招待成功才扣料理 |
| 家具与装饰 | 主线解锁、场景成长或纪念 | 布置场景 | 已拥有与已摆放应能区分 |

厨房建议先做选配方、检查食材、确认制作、成品入库四步，不做连续切菜和火候小游戏。配方画面直接显示所需与持有数量，缺少食材时给来源提示。

示例：春季收获蔬菜 → 制作一道田园料理 → 完成一次简单招待 → 得到一件纪念装饰。该示例不锁定具体食材数量、菜名或奖励数值。

共享库存只表示可用数量，场景进度各自保存。获得物品、消费物品和记录完成状态需要作为一次完整操作处理；快速连点、返回或刷新不能重复领取、重复扣除或形成负库存。

## 三消进度与存档兼容

- 保留现有主线关卡、每日挑战、牌局、道具、音量与故事记录，不重置旧玩家进度。
- 新场景入口从已有最远主线首通记录推导；重复刷旧关和每日挑战不能反复发首通解锁奖励。
- 优先复用每季六组建设的节奏，但入口开放不必等六组全满。具体对应关卡在首版试玩后确认。
- 第二年及以后保留已拥有物品、已建场景和收藏，不自动清空重开；年份是否扩展场景内容另行决定。
- 新增世界状态使用版本号，分开保存农场土地、航点、采山探索、暖屋布置与共享库存。
- 旧存档缺少新字段时补安全默认值；迁移可重复执行，不能重复赠送入门包或丢失原牌局。
- 暂不迁移现有存储技术，不增加账号或云同步承诺。仍需说明本机存档与不同浏览器、站点之间的隔离。
- 演示或验收存档使用隔离环境，不能把满解锁样例覆盖正常试玩存档。

## 美术素材与生产方式

沿用现有柔和色彩、手绘绘本底图和透明贴纸语言。现有四季背景与图集是风格参考，是否复用具体区域取决于入口与操作布局，不能把一整张静态画当成可交互物件。

| 类型 | 首批建议内容 | 交付与验收要求 |
| --- | --- | --- |
| 场景底图 | 春季农舍菜圃、最小厨房；后续海湾、山林、暖屋 | 保留操作区和安全区，不把文字或按钮画进背景 |
| 透明交互物件 | 土地、作物、农具、门、灶台；后续船、浮漂、山货、家具 | 独立透明背景，视角、轮廓和阴影一致，点按区域清晰 |
| 成长与反馈状态 | 空地、播种、幼苗、成熟；收获与制作反馈 | 同一物件各状态对齐，避免切换时大小和位置跳动 |
| UI与库存图标 | 种子、食材、料理、收藏、进入、返回 | 小尺寸可辨认，数量与文案由界面渲染，不烘焙在图中 |

生产顺序建议：先做春季农场的一张审美样板，确认构图、视角、配色和可点区域，再制作透明物件及状态图，最后扩展其它季节。

图像生成会计入图像功能用量，具体额度或费用以所用产品和套餐当时显示为准。本次只提交设计文档，不生成素材、不批量消耗图像用量；后续样板确认后再批量制作。

每批素材保留名称、尺寸、透明性、用途与来源记录；在真实手机比例中检查裁切、遮挡和文字可读性。动态图层应兼容减少动态效果设置。

## 分阶段范围与验收

### 阶段一 春季农场与最小厨房

先确认审美样板，再完成农舍入口、少量种植、收获入库、一道料理、一次简单招待或野餐反馈，以及返回主页。此阶段不开发夏秋冬玩法，只保留它们的设计方向。

验收要能完整走一遍「进入农场 → 播种照料 → 收获 → 制作 → 使用料理 → 返回三消」，玩家看得懂每一步，且能在任一步离开并恢复。

### 阶段二 夏季海湾与秋季采山

复用已验证的库存、厨房和收藏规则，分别做短航点钓鱼与短路线采山。先让普通资源循环成立，再加入少量珍稀发现；不同时扩张航海系统与复杂地图生成。

### 阶段三 冬季暖屋与全年连贯体验

接入家具摆放、来访小羊和料理招待，补齐四季返回、收藏展示及一致的操作反馈。是否增加更多作物、航点、路线和剧情，依据前两阶段试玩再定。

### 每阶段共同验收

- 所有入口可进入和返回；关闭面板、连续点击、切季节、后台恢复不会卡死或跳错场景。
- 同一收获只能领取一次；制作和招待不会重复消耗、扣成负数或吞掉结果。
- 刷新后保留有效进度；保存失败有提示，损坏或旧版本数据有安全回退。
- 四季独立状态不会互相覆盖；共享库存的每次变化在所有入口一致。
- 旧三消继续通过原有自动测试，牌局、道具、胜负判定、每日挑战与剧情无回归。
- 手机短屏、返回路径和减少动态效果可用；装饰不能遮住必需操作。
- 每阶段交付可玩的实际闭环和素材清单，不以静态效果图代替玩法验收。

## 需要在实现前确定的三件事

1. **玩法深度**：更偏几分钟轻松点按，还是允许一段更投入的经营与探索？这决定土地、路线和操作数量。
2. **成长节奏**：资源补充、作物生长和场景升级主要由场景操作、三消进度还是两者共同推进？所有具体数值与稀有概率暂不锁定。
3. **珍稀物处理**：珍贵蘑菇等只用于收藏，还是收藏登记后允许额外个体用于特殊料理？首个收藏不能被无提示消耗。

下一步建议先确定阶段一的玩法深度并制作春季审美样板，确认后再进入素材拆分与最小可玩闭环实现；本文提交本身不启动这些制作工作。
