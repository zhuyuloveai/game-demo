## 比例与锚点

PNG 原图不改；`tools/build-runtime-art.py` 生成最大边 512 px 的透明运行时版本，以有效 alpha 边界建立视窗及命中掩码。115 张 PNG 合计约 18.44 MB（十进制）。同一动物各姿态维持底部中点落地，具体种类大小和满栏站位由 `farm-animal-layout.mjs` 管理。

环境和建筑状态组件保持源 SVG 字节一致，源尺寸、地面锚点及 SHA-256 记录在 `farm-runtime-environment-metadata.mjs` 与独立 manifest 中；已是 2:1 的地面组件不可二次倾斜。PNG 人物姿态仍是静态图，未提供方向帧和骨骼动画。

- 围栏仍为 4×4，鸡6只、其余每栏5只，容量与经济不变。五种动物分别使用合适显示尺寸，两排脚点真正错开；背景棚屋与动物独立按画面深度排序。

## 分层栏舍 v2 接入（2026-10-26 后续更新）

本节取代上文关于默认栏舍底部中点、旧院落和常驻逐只徽标的描述。源美术来自 main `77a41898` 的 `shelter-layers-v2`，原始分层图、ORA、预览及作者空间标注均不修改。

- 正式场景使用五类设施各自的地面、建筑阴影、后栏、建筑和前栏，不再将旧完整棚屋 PNG 与代码围栏叠加。
- 新增 55 张运行时 PNG（约 2.30 MB）：25 张设施层、15 张动物姿态、15 张独立动物阴影。设施派生图为 600×500，动物为 360×280，保留完整共同画布。`tools/build-runtime-shelters.py` 可重建；空间标注仍以作者 1200×1000 原画布坐标保存，不能把半尺寸 PNG 坐标直接当作世界脚点。
- 所有层和动物脚点使用同一个等比例画布→世界变换。采用经校验的参考院落站位；每个状态以美术标注的接地点对齐，不按 alpha 包围盒下沿重新落地。鸡和绵羊在实图检查后分别以 0.92 / 0.95 倍缩放身体和独立影，脚点不变。逻辑 4×4、容量及存档不变。
- 镜像朝向同时反射设施层、动物站位、动物和阴影像素及透明命中。旧朝向保留原存档值；特殊皮肤没有对应新分层，继续旧素材回退，不悄悄替换皮肤。
- 正常状态每栏只显示一个小的待收/待喂提示；点击仅选择该栏和工具，不偷偷触发经济命令。选栏后显示单只状态。逐只点击与同栏拖扫仍使用独立身体 alpha，前栏实际像素遮挡会影响命中，透明矩形不会抢目标。
- 绘制与命中按各层真实深度处理，后栏不能借建筑层级抢前方动物。局部透视用可见像素交集判断，不因完整透明画布重叠而淡化无关栏舍；前后栏随所属设施一致淡化。退出恢复。
- 放置预览和布局缩略图也使用同一组层，不重复叠加旧代码院落。
