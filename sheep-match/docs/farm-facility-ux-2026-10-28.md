# 设施操作统一体验（2026-10-28）

## 原则与范围

统一的是操作规律，不是把所有设施变成同一种弹窗：先看到对象与状态，直接做常用操作，管理操作降为次级。采用现有美术，保留所有经济规则、库存数量、生产时间、留种保护、风险确认、存档与浏览器历史；不新增物种或玩法。

|设施|主要体验|不可隐藏的信息|次级管理|
|---|---|---|---|
|鸡舍|6只，3+3自然错位全见；底部饲料袋拖过即喂，产物点/划收|已有/容量、饥饿/待收、饲料库存|领养、迁移、布置；缺料时制作饲料直接可达|

## 验收合同

- 390px 与 360px 手机宽度下，动物无横向寻找；两排触区不重叠，5只不硬填6只。
- 机器最多9生产槽与9成品的关键容量明确；成品架满导致等待不能显示“制作中”。配方只有1–5种，优先全部可见。
- 计时、扣料、收取后不更换正在操作的指针所有者、不重排未操作对象。
- 二指/取消/失焦/Back/关闭只结束尚未提交的动作，已成功提交不回滚；单笔对同目标不重复扣除。
- 少料、满仓、只读、存档失败均以真实 core 结果反馈，不用提前乐观成功替代。
- 低矮横屏允许自然纵滚，主要工具不被浮层文案挡住。
- 云浏览器真实鼠标与合成 touch 分开记录；未经过原生手机验证不能声称真实 touch 全过。

## 云浏览器验收记录

- 360×640：鸡6只、牛/猪/绵羊/羔羊各5只均全可见，横向溢出0；3+3/3+2站位不重叠、产物绑定正确。
- 真实鼠标一笔跨两排喂6只鸡：饲料6→0、六只进入生产，逐只即时提交；缺料入口保留。合成触摸另行验证取消/重复/收取，不混同原生触摸。
- 360×640仓储容量、选物详情、底部操作同时可见；数量编辑不遮最终回收按钮。交易可视回归7/7，包括节点/焦点保留、滚动与选择保留、留种和准确到账。
- 360×640工厂满架9批+满队9槽、5种配方可见，无水平裁切；满架队列正确标“等待”而非制作中。浏览器合成触摸一笔收9批：面包26→35、成品架清空、队首开始生产。真实鼠标把面包配方拖入槽成功只排1批、小麦86→83。
- 低矮横屏动物区改为从顶部排版并允许纵滚，避免居中产生负滚动原点裁头；固定工具不随场地滚走。
- 工厂命中区排除sticky标题覆盖区域；配方全见后无需横向滚动，任意方向拖入槽一次提交，纯横移未入槽不扣料。
- 独立审查核对经济/存档核心无改；修复并回归动物纵滚、折叠管理焦点环、sticky遮挡命中。
- 本机云浏览器支持真实鼠标与CSS小屏，环境不支持获准的原生touch仿真。仍需部署后iOS/Android手机回归；本次不宣称原生触摸/SLO全部达标，也不部署。

最终全量测试及打包计数以提交说明为准。
