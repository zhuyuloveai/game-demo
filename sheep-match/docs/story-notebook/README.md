采用用户确认的第二版文案和八张绘本 CG。正文集中在 `story-data.mjs`，播放与笔记界面在 `story-notebook.mjs` / `story-notebook.css`，收录及演绎确认规则在 `story-progress.mjs`。

首页书本按钮打开笔记。季节目录、页码和八页索引均可翻阅；完成页可以重新演绎。第二个标签保留六组布置清单，包含后续年份。手机使用可滚动单页，笔记标题与关闭按钮保持可见；剧情画面与控制区适配动态视口。

演绎共三句，每句约 4.2 秒，末句等待确认；图片未载入或页面进入后台时不自动翻句。支持手动翻句、跳过、音乐开关及系统减少动态效果。结束、跳过和 Escape 均恢复首页季节配乐；沿用同一媒体元素，避免两首音乐叠加。

## 存档

- 收录始终由 `highestCleared + 1` 派生，无独立发奖计数。每日挑战、回玩旧关及重看剧情不会增加收录。
- `sheep-pasture-v1-stories` 存 `{version:1,acknowledged:[storyId...]}`。只接受当前已达成的 ID，播放开始即写入，防止退出或刷新后反复弹出。
- 老玩家没有剧情存档时，按原有主线进度安静补齐确认状态。游戏、主线、音量和静音存储键保持原有含义。
- 单次回首页只自动播放一段收尾；新季节开场等待实际进入。连续玩过多季时仅自动演绎最新收尾，旧故事全部可从笔记回看。
- 第 96 关后不增加第九张主线 CG。笔记显示累计完成的年份，后续年份继续发放场景布置。

## 美术来源

[sources.json](sources.json) 保留内置 ImageGen 的原始路径、生成方式和完整提示词。原始 PNG 位于设计预览目录，正式版本使用 `assets/story/*.webp`。采用 lossless WebP 编码，八张图片转换后均逐像素比对 RGBA 相同，未改构图或内容。首屏不预加载其余七张，翻页时只加载所选页。

## 验证

运行 `node --test sheep-match/tests/*.test.mjs`。新增剧情测试覆盖全部收录门槛、旧档补齐、损坏数据、播放确认持久化、奖励落位门槛、延后开场、跨年以及连续闯关时的剧情积压处理。隔离端口的浏览器测试通过真实选牌完成第 24、96 关，并验证演绎、回看、静音、手机短屏和布置清单。发布验证脚本逐个检查 44 个正式资源，设计预览、来源清单和测试不公开部署。
