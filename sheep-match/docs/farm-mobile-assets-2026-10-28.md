# 手机交互、画面稳定与首批新素材验收（2026-10-28）

基线：`38ae542218c470e68998fcc6f8d4add46d31ee5d`。本次仅代码/素材集成，不部署、不改生产存档。

## 已修复
- 鸡舍饲料袋被宿主 `.farm-scenes button` 的 `touch-action: manipulation` 覆盖。工具改为高优先级 `none`，动物行仍允许横向滚动。
- 工具拖动由稳定 overlay 捕获指针，document 兜底；取消、第二指、失焦、隐藏、关闭立即结束笔画。逐只即时提交且去重，不提交被横向裁掉的动物。工具停在行边缘时有上限地自动横滚，让六只动物可一次连续操作；普通行滚动不变。
- 动物动画在手势短暂暂停时保留已解码帧，而不是先切静态；DOM 局部更新不覆盖同一状态的动画源。真正饥饿/生产/成熟状态改变仍覆盖旧图。保留原随机相位与动效强度，不以关闭动画掩盖问题。
- 机器分层在 decode 完成前/失败时保留静态 fallback；同 ID 换机器类型不会继承旧的隐藏状态。
- 浏览器 history 覆盖主页/主线/农场/内部场景/鸡舍工坊/牧场故事及确认框，去掉原左上“返回原操作”，保留右侧 ×。Back/Forward 不重放经济命令；根页允许离站，无无限哨兵。局部工具 sheet 不独立入栈，Escape 先关工具。系统边缘手势仍由浏览器决定。
