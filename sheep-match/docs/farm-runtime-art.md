# 正式农场静态 PNG 适配

来源为 main `52e6c187b8160cd69227f28e148c75dde9ab5bbe` 已有的 `docs/art-packs/sumikko-farm-v1/assets/` 及 `plant-states/assets/`，没有新增生成图、购买素材或改动原稿。实际查看了基础 63 张及新增 42 张植物状态的联系表后适配。植物包里的两张预览截图不作为运行时素材。

## 包体与显示

- 105 张原稿共 99,367,911 bytes；运行时透明 PNG 共 17,239,306 bytes，缩小约 82.7%。
- `tools/build-runtime-art.py` 用 Pillow 将原稿等比例缩至最长边不超过 512；不拉伸、不倾斜、不改变颜色/造型。原稿完整保留。
- 运行时目录 `assets/farm-runtime/`；`manifest.json` 记录每张来源、原稿 SHA-256、尺寸及字节数。
- `farm-runtime-art-metadata.mjs` 记录透明边界、底部中心落点及 64×64 alpha 命中采样；数据仅用于展示，不写入存档实体。
- 新植物状态按上游 `plant-states/manifest.json` 的 `displayScale` 等比缩放，围绕底部中心落点；不把幼苗放大成成年植株尺寸。
- `renderRuntimeArt` 用裁剪 viewBox 显示 PNG，保持原比例；`runtimeArtHit` 在裁剪后视觉矩形中检测透明区。它不是整张矩形命中，也不是像素级精确：64×64 采样在轮廓边缘存在少量近似。地块逻辑占地仍须由世界模块单独处理。

## 覆盖和有意保留的差距

| 内容 | PNG 覆盖 | 状态策略 |
| --- | --- | --- |
| 作物 | 11/11，含辣椒、黑豆、番茄 | 幼苗、生长、成熟三态全部 PNG（共 33 态）；前两态按实际播种→成熟时长的一半区分 |
| 果植 | 5/5，含 blueberries | 幼树、生长、成熟、待复苏、枯死五态全部 PNG（共 25 态）；首次生长前半显示幼树，后续轮次不退回幼树 |
| 生产机器 | 12 类/13 实例（两台饲料机共享图） | 基础造型 PNG；施工仍叠加原施工状态；队列/完成品不在本模块更改 |
| 动物与棚舍 | 5/5 动物、5/5 基础棚舍 | 动物是一张静态姿势，不是新的逐帧动画；行为、喂养/产物标识保留给世界模块；已获得 Floral 外观继续原 SVG |
| 核心建筑 | 小屋、粮仓、货仓 | PNG |
| 装饰 | 16 种普通装饰、4 种奖励装饰 | PNG；徽章仍原 SVG |
| 其他 pack 图 | NPC 摊位、订单板 | 元数据可用；正式世界没有对应实体时不凭空新增 |
| 地面与自然物 | 本 PNG 适配器不负责 | 新 terrain SVG 的接入由世界模块单独处理；不把它们计入这 105 张 PNG |

新增植物状态已接入，但静态 PNG 仍未覆盖所有地形、施工、外观或动物动作帧。本次不能宣称所有画面均已统一成新美术，也不能宣称像素级还原。保留 Floral 外观和其他仍无适用替代的 SVG 是为了不丢失游戏状态与已领取外观。动物的轻晃等展示效果可在世界层实现，并须服从减弱动效开关。

## 验证
