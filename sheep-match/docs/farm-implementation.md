# 核心牧场 v0.4 实现与验收记录

实现基线：`docs/farm-design/README.md` 和其 `project-parameters-v04.json`。不部署、不接真钱或虚构社交，不改无限三消主线。

## 模块

- `farm-core.mjs` / `farm-config.mjs`：集中经营规则、冻结生产参数、原子命令。
- `farm-layout.mjs`：正交占地、出口可达、草稿位置应用。
- `farm-save.mjs`：双快照校验、写失败回滚、唯一写者与导入导出。
- `farm-scene-host.mjs`：正式全屏场景路由，复用 `createFarmStore.dispatch` 的持久化事务；来源往返保留调用界面和选择。
- `farm-scene-world.mjs` / `farm-scene-trade.mjs` / `farm-scene-management.mjs`：场景化地图、物件交易与成长/设置；原 `farm-ui.mjs` 留作旧版回归参考，不再被正式 runtime 挂载。
- `farm-linkage.mjs` / `farm-match-ui.mjs`：24关独立牌局及首通事务，复用原`engine.mjs`。
- `farm-stage-layouts.mjs`：每关实坐标模板及3份确定种子；72局均须完整回放，不以搜索超时当可解。

## 道具账本边界

原应用只有每局免费撤回3、洗牌2、移出1；没有持久共享付费道具余额。支线沿用这些每局工具，将棋盘和工具同保存在农场payload，不消费或复制原主局工具。因此A44的跨key共享扣款协议不触发，未来若加共享余额，须先另行实现恢复桥，不得直接复制。
