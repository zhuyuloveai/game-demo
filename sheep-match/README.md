# 羊羊牧场

「羊了个羊」玩法风格的原创牧场主题浏览器小游戏，使用原生 HTML、CSS、JavaScript 和手绘风格 SVG，无构建步骤，无第三方运行依赖。

[在线试玩](http://1.92.214.23/) · [部署与回滚](deploy/README.md)。线上沿用原小厨合合的入口。

在本目录执行 `python3 -m http.server 8017 --bind 127.0.0.1`，打开 <http://127.0.0.1:8017/>。也可以从仓库根目录启动服务后访问 `/sheep-match/`。

macOS 可以双击 `launch.command` 启动本地服务；默认端口 8017，命令行可用 `SHEEP_PORT=8020 ./launch.command` 更换端口。服务仅监听本机。

- 明确切换移动、种植、收获和布置模式；划过田地抬手一次提交，第二指或离开地图取消整笔。回田/缩放与田地列表支持小屏和键盘替代操作。

## 我的牧场首页

打开游戏先进入贴纸绘本风格的牧场首页；云朵、太阳、星星、草叶，以及解锁后的动物、水波和炊烟分别轻轻运动，支持系统减少动态效果设置。

- 点击「开始／继续闯关」进入当前牌局。关卡左上角的小房子返回首页，暂停计时，并保留牌面、收集盒、临时草篮、撤回记录与道具次数；刷新后仍可续玩。
- 主线每首次通过四关，获得一组季节专属布置。春日花溪、夏日海风、秋日果园、冬日雪乡采用不同地形、建筑、动物和构图；首页左右滑动、方向键或季节按钮切换。每季六份礼物：第 24/48/72 关立即开启夏/秋/冬，第 96 关开启下一年春季，旧年份保留并可回看。未开启季节可预览空场景，浏览不会改变关卡或领取奖励。
- 奖励由已有最远通关记录恢复，旧存档直接补齐对应布置；每日挑战和重复刷旧关不重复发奖。首页书本入口打开「牧场笔记」，包含「四季故事」与「布置清单」。
- 首页按正在浏览的季节播放配乐，进入牌局按关卡换曲，返回首页恢复所看场景的曲目；共用音乐开关与音量。四季插画、布局和生成提示词见 [四季设计说明](docs/farm-designs/README.md)，旧版素材来源保留于 `docs/farm-assets.md`。

## 牧场笔记与剧情

- 每季两张 CG，共八张。第一次来到春季播放开场；第 24 / 48 / 72 / 96 关的第六组布置领取、落位后播放对应季节收尾。下一季开场等首次进入该场景再演绎，继续闯关不会被连续剧情打断。
- 三句旁白、轻微镜头推进和季节粒子，支持自动 / 手动翻句、跳过、音乐开关。复用游戏唯一的背景音乐播放器；播放故事时按故事季节换曲，结束后恢复首页正在浏览的季节，保留静音和音量偏好。
- 收录资格只由最远主线首通进度计算。跳过仍收录；播放开始时保存确认状态，刷新后不重复强制弹出。旧玩家首次升级安静补齐已达到的页数。连续闯过多季再回首页时只演绎最近完成的一季，早先剧情可在笔记中回看。
- 第二年起仍保留八张主线 CG，新增累计年份印章，布置清单支持跨年浏览。锁定页显示解锁条件，不显示插画和正文。
- 已确认文案和 CG 见 [剧情说明](docs/story-notebook/README.md)。八张图片无损转为 WebP，逐像素验证与批准的 PNG 一致；只加载正在查看的插画。

## 四季牧场与手机布局

- 第 1 关为春、第 2 关为夏、第 3 关为秋、第 4 关为冬，此后每四关循环。季节由关卡编号决定，重开、刷新和回玩保持一致；每日挑战按其关卡难度对应季节。
- 整体为简单扁平卡通牧场：中央草地、外围栅栏，边缘的小屋、树、草垛和仓房随季节变化。四个 SVG 在 `assets/seasons/`，上下场景与中间围栏分别适配布局高度。
- 卡牌保留原有卡通物品，使用奶油白牌面、暖灰遮挡牌和灰褐色边框。字体沿用小厨合合的自托管站酷快乐体，许可与来源保存在 `docs/fonts/`。
- 页面使用浏览器实际动态视口与安全区，顶部只显示品牌、当前关卡、剩余牌数、音乐和更多入口。关卡路线、每日挑战、说明和音频设置收进原生可滚动面板，面板打开时暂停计时。
- 暂存槽和三个道具保留在底部；移出卡牌后，临时草篮使用暂存槽上方的一行，减少对棋盘高度的挤占。棋盘按可用空间等比缩放，卡牌的逻辑坐标和遮挡判定不变。极矮横屏允许纵向滚动，避免裁掉操作入口。

## 玩法

- 选择未被上层遮挡的牌，放入七格暂存槽；三张同图案自动消除。可选顶牌下方完全或近同位的叠牌在左侧显示中性牌背边缘；每张隐藏牌对应一道边缘，不显示数字。总展开宽度最多 12px，超过四层时压缩间距；极深堆的边缘会较密，读屏仍可获取准确张数。提示不显示底牌图案，也不改变遮挡和点击规则。
- 第七张先检查能否消除，再判定失败；清空牌区、暂存槽和临时草篮即可获胜。
- 无限闯关：第 1 关开始，通关解锁下一关，关卡路线随当前关卡向前滚动，可以回玩已解锁的关卡。「继续闯关」可返回最新进度。
- 难度按关卡编号计算，增加牌量、图案和叠层深度。前期平缓教学，后期牌量以对数速度继续增长，避免关卡数量变多时牌量暴涨；图案最多使用现有的 12 种。
- 每次普通开局会随机生成牌堆形状、缺口、层间错位和图案。点击「换张地图」、失败后重新挑战、通关后继续都会生成新地图。每日挑战采用北京时间日期固定种子，当天地图可重复挑战。
- 每局免费提供撤回 3 次、洗牌 2 次、移出 1 次。撤回还原一次选牌及其消除；洗牌只打乱剩余牌面；移出将槽内最前面至多三张放入草篮，点击取回。洗牌或移出后清空撤回历史。
- 音效可开关。牌局、计时、道具、撤回历史、最远通过关卡与解锁进度存入本机 localStorage；隐藏页面、弹窗和生成地图期间暂停计时。每日挑战与主线牌局分开保存，可以从每日挑战回到主线继续。回玩旧关、每日挑战不会提前解锁后续关卡。
- 操作音效默认开启并保留已有静音偏好：选牌使用清脆的碰牌声，三张消除使用短和弦，撤回、洗牌、移出、取回、胜负及按钮操作有不同的声音。音效在本地合成，与背景音乐独立；后台或关闭音效立即停止，快速连点限制同时发声数量。消除不再显示中央横幅或浮动提示，槽中卡牌更新无入场动画，读屏仍能获得消除播报。
- 背景音乐为本项目原创四季器乐曲：春日蹦蹦芽、夏日汽水湾、秋日栗子舞、冬日雪花铃。[配器、循环长度与生成说明](media/README.md)。首次点击游戏或播放按钮后开始循环，随关卡季节自动换曲，同季节操作不重启；音乐有独立开关和音量，刷新记住设置，进入后台暂停、回到页面恢复。音效开关仍独立控制选牌与消除提示音。
- 切换关卡或重开进行中的牌局会提示确认。失败后仍可用撤回或移出救场。

`engine.mjs` 为独立引擎。地图在每层网格上随机生长连通形状，上层须有下层支撑，同层卡牌不重叠，再将成组三张的图案随机分配。

每个随机候选使用带状态记忆和等价分支剪枝的搜索器寻找完整通关路径。无解或搜索达到预算仍未找到解的候选都会丢弃并重新随机。为避免高难地图长时间阻塞，常规随机尝试最多 4 次、每次搜索最多 2500 个节点，随后改为随机生成地图并沿合法路径构造图案。两种方法均须通过独立的逐步回放验证，确认每次选牌无上层遮挡、槽位不溢出、最终全部清空，才允许开局；不会把搜索超时当成可解。

保证新开局存在一条不使用道具的解；玩家后续选牌或洗牌仍可能使局面失败。地图在 Web Worker 中生成，准备新地图时显示等待状态，避免搜索阻塞界面。`solution` 仅用于生成器验证，恢复存档时不保留。存档包含完整随机地图几何形状，旧版固定地图和三关版随机地图存档均可继续；下一次开局使用无限关卡的难度曲线。

从仓库根目录运行上述测试。覆盖 360 个早期和后期牌局的完整通关、第 1000 / 10000 关的地图及存档、连续解锁 1000 关、难度递进、旧版迁移，以及遮挡、满槽结算、道具和损坏存档。

选牌以约 560ms 的柔和弧线飞入收集盒，可连续点击。飞行落地后再完成三消与结算；撤回、切图、后台及视口变化会清理动画，游戏进度仍即时保存。系统减少动态效果偏好下即时落位。

三消效果仅在收集盒内播放：三张牌短暂亮起、轻微放大，再缩小淡出（320ms），配合落地消除音效。效果期间继续接受选牌，连续操作重绘不会重启动画；撤回及换关会一并清理。
