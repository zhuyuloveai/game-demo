# 羊羊牧场

「羊了个羊」玩法风格的原创牧场主题浏览器小游戏，使用原生 HTML、CSS、JavaScript 和手绘风格 SVG，无构建步骤，无第三方运行依赖。

[在线试玩](http://1.92.214.23/) · [部署与回滚](deploy/README.md)。线上沿用原小厨合合的入口。

在本目录执行 `python3 -m http.server 8017 --bind 127.0.0.1`，打开 <http://127.0.0.1:8017/>。也可以从仓库根目录启动服务后访问 `/sheep-match/`。

macOS 可以双击 `launch.command` 启动本地服务；默认端口 8017，命令行可用 `SHEEP_PORT=8020 ./launch.command` 更换端口。服务仅监听本机。

## 玩法

- 选择未被上层遮挡的牌，放入七格暂存槽；三张同图案自动消除。
- 第七张先检查能否消除，再判定失败；清空牌区、暂存槽和临时草篮即可获胜。
- 无限闯关：第 1 关开始，通关解锁下一关，关卡路线随当前关卡向前滚动，可以回玩已解锁的关卡。「继续闯关」可返回最新进度。
- 难度按关卡编号计算，增加牌量、图案和叠层深度。前期平缓教学，后期牌量以对数速度继续增长，避免关卡数量变多时牌量暴涨；图案最多使用现有的 12 种。
- 每次普通开局会随机生成牌堆形状、缺口、层间错位和图案。点击「换张地图」、失败后重新挑战、通关后继续都会生成新地图。每日挑战采用北京时间日期固定种子，当天地图可重复挑战。
- 每局免费提供撤回 3 次、洗牌 2 次、移出 1 次。撤回还原一次选牌及其消除；洗牌只打乱剩余牌面；移出将槽内最前面至多三张放入草篮，点击取回。洗牌或移出后清空撤回历史。
- 音效可开关。牌局、计时、道具、撤回历史、最远通过关卡与解锁进度存入本机 localStorage；隐藏页面、弹窗和生成地图期间暂停计时。每日挑战与主线牌局分开保存，可以从每日挑战回到主线继续。回玩旧关、每日挑战不会提前解锁后续关卡。
- 操作音效默认开启并保留已有静音偏好：选牌使用清脆的碰牌声，三张消除使用短和弦，撤回、洗牌、移出、取回、胜负及按钮操作有不同的声音。音效在本地合成，与背景音乐独立；后台或关闭音效立即停止，快速连点限制同时发声数量。消除不再显示中央横幅或浮动提示，槽中卡牌更新无入场动画，读屏仍能获得消除播报。
- 背景音乐为三无 Marblue 演唱、ilem 词曲的《普通DISCO》，[来源与非商业使用说明](media/README.md)。首次点击游戏或播放按钮后开始单曲循环，音乐有独立开关和音量，刷新记住设置，切换关卡连续播放，进入后台暂停、回到页面恢复。音效开关仍独立控制选牌与消除提示音。
- 切换关卡或重开进行中的牌局会提示确认。失败后仍可用撤回或移出救场。

`engine.mjs` 为独立引擎。地图在每层网格上随机生长连通形状，上层须有下层支撑，同层卡牌不重叠，再将成组三张的图案随机分配。

每个随机候选使用带状态记忆和等价分支剪枝的搜索器寻找完整通关路径。无解或搜索达到预算仍未找到解的候选都会丢弃并重新随机。为避免高难地图长时间阻塞，常规随机尝试最多 4 次、每次搜索最多 2500 个节点，随后改为随机生成地图并沿合法路径构造图案。两种方法均须通过独立的逐步回放验证，确认每次选牌无上层遮挡、槽位不溢出、最终全部清空，才允许开局；不会把搜索超时当成可解。

保证新开局存在一条不使用道具的解；玩家后续选牌或洗牌仍可能使局面失败。地图在 Web Worker 中生成，准备新地图时显示等待状态，避免搜索阻塞界面。`solution` 仅用于生成器验证，恢复存档时不保留。存档包含完整随机地图几何形状，旧版固定地图和三关版随机地图存档均可继续；下一次开局使用无限关卡的难度曲线。
