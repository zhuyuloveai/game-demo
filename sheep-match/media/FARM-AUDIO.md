# 农场与农场消消乐原创音频

新增两首独立主题及14个分层交互音效，旧四季音乐原样保留。没有使用第三方歌曲、录音、采样包或 SoundFont，旋律、和声、音色与节奏全部在可复现生成器中定义。

## 两首主题

- `farm-life.m4a` /《牧场慢慢长》：G大调，96 BPM，4/4拍，32小节，80.000秒。暖木琴、拨弦、柔木管与轻刷节奏；A主句、B木管应答、疏朗A再现、B回归和属和声引入。
- `farm-match.m4a` /《菜篮蹦蹦舞》：G大调，120 BPM，4/4拍，40小节，80.000秒。跳跃木琴、拨弦切分、轻手鼓；A/B、A变奏、半密度桥段与B再现。与农场主题共用短小的1–3–2动机，但旋律、节奏与段落明显不同。

格式均为 AAC-LC / M4A、160 kbps、44.1 kHz、立体声。循环范围均为 `[0, 80)` 秒。原始合成的尾音及房间反射循环回卷，维持完整小节，最后属音引向开头主和弦；首尾仅3毫秒微包络保护编码边缘，没有人为添加尾部静音。

M4A包含编码延迟/有效时长信息。直接解码为裸PCM时ffmpeg会返回704个末帧补齐样本，使用Web Audio缓存时请显式设置 loopStart=0、loopEnd=80；HTMLMediaElement的实际无缝程度依浏览器实现，需要真机长时间试听，不应声称已证明所有浏览器采样级无缝。

## 接入

`../farm-audio-manifest.mjs` 只导出静态数据，不创建播放器、不下载或自动播放：

- `FARM_TRACKS.farm` / `FARM_TRACKS.match`：`key`、`title`、`description`、`src`及循环/建议音量。交给已有唯一 `createBackgroundMusic` 的 `setTrack`，不要新建第二个BGM播放器。相同场景重复渲染不重启曲目。
- `FARM_SFX`：cue名称到绝对资源URL。
- `FARM_SFX_GAINS`：各cue的建议播放增益0.65。建议共享用户音效开关、后台暂停规则，限制短时重复触发及并发，批量收获不要为每颗作物叠加完整音效。

背景音乐建议音量：农场0.35，消消乐0.32。音效是16位44.1 kHz单声道WAV，总计约0.85 MB：

- `plant`：低频落地感与上行木琴，种下。
- `harvest`：拨弦、木琴上行与柔木管，收获。
- `feed`：柔和低音及两步拨弦，喂食。
- `product-ready`：三音应答，产品就绪。
- `coin`：短促双音，收金币。
- `button`：很短的木质确认音。
- `soft-error`：柔和下行双音，不使用刺耳报警。
- `upgrade`：分层上行与柔和终止和弦。
- `first-clear`：约1.5秒小庆祝句，独立于普通消除。
- `water`：三颗水滴感木琴及轻噪声。
- `animal`：原创音乐性啁啾，不冒充真实动物录音。
- `tile-pick`：轻拨弦选牌。
- `tile-match`：上行三音消除。
- `combo`：更高音域的连击应答。

## 重新生成及验证

需要 Python 3、NumPy、ffmpeg；运行 `python3 sheep-match/tools/compose-farm-themes.py`。生成器复用 `compose-seasons.py` 的纯合成音色函数，不修改原四季乐谱或媒体。可用 `--output /tmp/farm-audio` 输出到其他目录。

`farm-audio-report.json` 记录原始PCM与M4A实际解码后的峰值、RMS、首尾跳变、静音窗口、各文件时长/格式。验证覆盖：所有样本有限、无削波、两曲实际时长、每秒非静音、AAC解码、首尾边缘、所有WAV头及电平。AAC为有损编码，不要求不同ffmpeg版本字节一致；同一工具链的固定随机种子可重复生成。

未进行主观听觉试听，不能据此宣称混音已通过听感验收。发布前建议耳机/手机扬声器各听两圈，并快速种植、收获、切换场景、静音和后台恢复，确认长期听感、音效叠加与真实播放器循环衔接。程序QA结果不是主观试听的替代品。
