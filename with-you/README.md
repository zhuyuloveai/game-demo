# With You · 本地月版原型

现代都市生活、经营与女性角色恋爱试玩。新开局30天、每天两个时段，共60次生活行动；月底收束后可继续按周经营。原七天与经营档保留原进度，新月份需通过游戏内重启开始。

## 启动与存档

本目录执行 `npm start`，打开 http://127.0.0.1:8017/ 。无需安装依赖。

进度自动存于浏览器localStorage。同一浏览器、同一站点共用当前进度；不同设备/浏览器互不影响，没有账户或云同步。游戏内重启覆盖当前生活，已解锁结局CG单独保留。反馈入口可下载当前记录。

## 这版可以玩什么

- 公寓主页：书桌模拟电脑、手机模拟聊天、出门模拟城市地图。工作、学习、休息有常用快捷安排，仍各消耗一个行动时段，并保留CG与回顾。
- 林知夏、沈以宁各12段相处事件和月底收束。事件最早开放日为1/2/3/4/6/7/10/13/16/19/23/27，晚到可以补。同一人物每天见一次。
- 月底至少6次相处、亲近12可选择交往，手记/月历显示实际进度；同一章保留一段恋爱关系，另一人可作为朋友相处。朋友和独自成长都有结局。
- 工作收入、学习能力、精修选项、休息恢复，个人项目及后续工作内容持续到月中以后。月历、城市日常、阶段消息与结局回顾依据日期及真实经历变化。
- 市场3种商品、2只虚构股票，买卖各2%费用；持仓浮动不直接变成现金。
- 三种公司，一次一家，自持股权；稳健/积极/暂停，扩张、现金不足停单、按累计投入70%清算。投资预览显示剩余现金、下期成本和真实缺口。
- 5000元短片，两期后分账，可能亏损；净资产1亿元解锁1000万元长片。每期最多5张20元彩券，概率与期望返还明示，全部仅游戏币。
- 已相识角色可收到玩家主动分享的真实创业、扩张、首片上映近况。里程碑按联系人去重，刷新不重发，也不增加金钱、亲近或行动时间。

第一章每晚结算一期，第二章每次生活行动推进一周。市场交易与配置不消耗时段。公司需要可用现金，持仓不会自动卖出；未完成影片在章后保留。

## 美术与操作

电脑端16:9场景界面，12张概念CG：公寓、两位角色、三处生活地点、市集与写生场景、四种结局。可收藏11张，公寓不计收藏。Space继续阅读，H隐藏/显示界面，Esc关闭菜单。

图片由内置image_gen生成，项目素材在 `assets/`。提示词见 `ART-PROMPTS.json`、`SCENE-PROMPTS.json`、`HOME-PROMPT.json`、`ENDING-PROMPTS.json` 与新增 `MONTH-ART-PROMPTS.json`。

## 范围与结构

这是用于确定玩法方向的纯HTML/CSS/JavaScript原型。`engine.js`处理生活状态；月份剧情与收束分布在 `month*.js`；`economy.js`处理经济；`app.js`、`devices.js`、`finance-ui.js`呈现界面；`storage.js`兼容旧存档。

矿业、足球队、IPO/增发融资、员工产品管理、多家公司、语音和长篇第二章尚未实现。股票为虚构报价模拟。当前优先桌面体验，没有后端或真实支付。

本次仅本地修改，公网旧版未更新。经营细节见 `ECONOMY.md`；部署历史见 `deploy/README.md`。
