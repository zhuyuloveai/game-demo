# 第一周体验合同

默认实现取向：双角色保留完整路线，林知夏作为细化重点。保持现有CG、16:9房间枢纽和设备隐喻。核心时间预算14次行动，不新增服务器或账号。

七日节奏：搬家认识 → 分享近况 → 暴露难题 → 自己的生活与回应 → 支持与边界 → 周末邀约 → 回看与约定。

验收维度：
- 人物初见不能直接跳周日约会；每天相处有节奏限制和清楚可用提示。
- 亲近之外留下具体记忆，结束时回应至少一个实际选择。
- 工作呈现累积项目进展，学习改变机会，休息持续可用。
- 消息按日期/关系推进，同一条回复不可无限重复刷屏。
- 周末选择明确且不会被另一场约会静默覆盖。
- 新玩家在房间知道当天可以做什么与需要期待什么。
- 初识、成长、关系各路线都能完整结束；中途刷新、重启、回忆可用。

AI评审是设计假设和操作证据，不能代表真实玩家心动、留存或付费意愿。
