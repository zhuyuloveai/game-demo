# 小狗厨房 · 双风格环境界面

同一份 v4 进度、真实 7 列 9 行 63 格与 422 项物品，在「经典厨房」和「围坐岛台」之间即时切换。手机 → 厨房设置 → 厨房风格。经典厨房保留原来奶油、暖灰、浅木配色和 CSS 实物造型；岛台使用窗光、水槽、浅蓝柜体、蜂蜜木台面以及独立位图物件。

375×667 **内容视口**中棋盘约 x=19.1、y=166、336.8×433px，单格约 48.1px。末行在 y≈599 内，底部入口 y=607–667；页面不纵向滚动。更短/更宽的视口根据可用高度收窄料理板以维持方格，仍显示全部 63 格。`100dvh` 和安全区参与计算；弹窗独立滚动，只有订单区允许横滑。桌面厨房居中，最大 430×780。

普通顾客头像贴小票左边缘，主线是独立色纸签。小狗保持用户提供的白色线条「M 帽小狗」身份和原动画素材。等级、剩余生产次数留在详情/图鉴，不覆盖物品；冷却时间、锁定、气泡和选中反馈保留。长物品说明在 44px 区单行省略，点「更多」看完整详情。

## 主题与进度

`kitchen-style.mjs` 管理独立偏好键 `little-kitchen-style`，值为 JSON 字符串 `classic` 或 `island`。有既有存档、无有效偏好时默认经典；新厨房默认岛台；显式偏好优先。存储不可用时仍可在本次会话切换。

切换只设置根元素的 `data-kitchen-style` 和外观偏好，刷新设置面板；不调用创建游戏、迁移、tick、领奖、重置或游戏存档函数。切换时取消正在进行的拖动、清除悬浮图与落点。两种外观共用同一个内存状态、事件委托和 `little-kitchen-save-v1`，棋盘/订单/仓库/章节/计时与资源不复制、不重置。

基础组件、交互反馈在 `style.css`，原有物件与面板在 `scene.css`，紧凑几何与岛台场景在 `island.css`，经典场景覆盖在 `classic.css`。新环境只引用项目内 `assets/island-*.webp`，约 110 KiB；没有远程生成地址或图片文字作为实时数值。素材提示词和处理见 [生成记录](art/KITCHEN_ISLAND_ASSETS.md)。
