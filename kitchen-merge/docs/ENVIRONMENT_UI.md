# 小狗厨房 · 环境界面

2026-10-16 确认的环境界面接入原游戏引擎，保留 7×7 棋盘、11 类食材厨具、生产器、订单、食谱、收纳、礼物、道具、音效和原浏览器存档。

游戏和厨房标识统一为「小狗厨房」。吉祥物为白色线条小狗店长，左上角显示同一形象的头像与游戏等级；现有配色、厨房环境和棋盘布局保留。

## 章节与兼容

开店手账使用原 `stage` 字段。旧档已经完成的阶段直接对应已完成章节，金币、电量、星星、棋盘、仓库、礼物及设备均保留；存档键及版本保持兼容。品牌更名后继续使用 `little-kitchen-save-v1`、`little-kitchen-v1-backup` 及原声音偏好键。

首章要求发现吐司、交付一份订单和烹饪一次，奖励咖啡工作台及 80 金币。后续章节按现有料理类别、累计交单和烹饪推进；原设备解锁顺序及收纳奖励保持。所有任务所需物品都来自已解锁设备。

章节不消耗星星。奖励使用明确的章节号校验，防止重复点击越过章节。设备和礼盒进入待领取队列，台面满时继续由小狗店长保管。旧 `renovate` 引擎接口保留给兼容测试，当前界面不提供装修入口。

## 资源与美术

电表采用圆角方形奶油外壳，浅灰绿液晶屏显示电量，配有闪电、小指示灯与散热缝。小猪采用正面、头身一体的椭圆轮廓，余额位于肚子下部，背部投币口露出半枚金币；星星罐保持玻璃和折纸星星材质。合成板与木桌保留明显的高度差，食谱、手机、竖款收音机与小狗店长在桌面紧凑排布。

小狗复用用户本机 Codex 自定义宠物「M 帽小狗」的动画图，原样复制到 `dist/assets/puppy-sprites.webp`。通过 CSS 帧定位展示头像和桌面动画，保留原图的白色线条、帽子及动作；平时轻轻呼吸，点击提示会招手，交单和章节领奖会开心跳动；弹窗打开、页面隐藏时暂停，减少动态效果时使用静止首帧。资源自托管，无运行时宠物服务依赖。

电表造型参考：[Octopus Energy 卡通电表](https://octopus.energy/blog/renting-with-a-smart-meter/)，只参考外壳、液晶屏和简化细节，运行素材由 CSS 绘制。

造型参考：[圆鼓陶瓷小猪](https://la-tirelire-francaise.com/products/tirelire-cochon-rond)、[Legami 小猪存钱罐](https://www.minimomentsscotland.co.uk/products/legami-coin-bank-piggy-1)。游戏造型由 CSS 绘制，不包含商品照片。

字体为自托管站酷快乐体；许可和可验证来源存于 `docs/fonts/`。界面无运行时外部资源依赖。扩展数值方案未接入本次运行版本。

## 验证

42 项引擎测试覆盖章节、旧档、满盘、重复领奖及全部章节可达性。浏览器验证 320、375、390、430 宽度，真实合成、收纳/取回、交付、烹饪保留厨具、首章领奖、刷新恢复、环境入口和音频开关。

## 手机可用高度

订单保留原来的悬挂纸签、夹子与锯齿纸边。42px 顾客头像露在纸签上方，名字位于头像右侧；底部同一行左侧显示金币和许愿星，右侧显示完成状态与交付按钮。按钮至少 44px 高，纸签高度为 98px，订单场景为 198px，短屏为 190px。物品信息栏保持 44px，长说明单行省略并可从“更多”查看。章节便签压成单行，桌面物件紧凑排布。

料理板使用台面内部的全部可用宽度，棋盘保持正方形；取消根据屏幕高度缩窄料理板的限制。页面最小高度沿用 `100dvh` 与安全区，内容超过可视高度时纵向滚动。320、375、390、430px 屏幕下，棋盘分别为 292、337、352、392px，四周仅保留台面边缘和板沿。实测 390×744 的页面内容高 804px，375×667 为 771px；无横向溢出，订单奖励与状态并排且不遮挡，短屏滚动后桌面入口正常可用。

## 棋盘点击与拖动

点击普通物品、资源物品、气泡或锁定格只更新选中与信息栏；连续点不同物品不会移动、交换或合成，再点同一物品保持选中，点击空格取消选择。未锁定的生产器沿用点击出货并选中的快捷操作。拖到相同物品合成、不同物品交换、空格移动；锁定和气泡的限制沿用引擎规则，拖动结束后，浏览器补发的点击事件继续抑制。
