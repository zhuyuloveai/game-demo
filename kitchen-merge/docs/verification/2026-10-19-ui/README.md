## 无主线订单时保留店长

复现：`?qa=chapter`交付本章最后一单后，主线卡片移除，订单列表横向偏移60px，小狗移动到屏幕左侧之外。修复后，没有主线时把原有店长节点放在订单滚动区外，为普通订单留出独立区域；状态切换时归零订单滚动位置。有下一章主线时复用同一个节点并移回主线卡片，不创建重复入口。
