# 物品呼吸与交互提示 · 2026-10-19

正式运行代码位于 `dist/item-motion.css`、`dist/item-presentation.mjs` 和 `dist/app.mjs`。

## 设计依据

参考[肥鹅棋盘公开截图](https://m.ali213.net/news/gl2408/1487873.html)中生产物件的黄色提示和可开启物件右上角标记；实际打开查看了[棋盘局部图](https://img1.ali213.net/glpic/2024/08/31/584_20240831104946487.png)。参考视频页未取得可稳定逐帧检查的画面，因此下列节奏是本项目在44px格子内调整的参数，不声称复刻原游戏时长。

- 普通物品以底部为支点，3.2秒轻微缩放；可操作物品呼吸幅度稍大，各物品错开相位。WebP本体运动，接触阴影保持在格子底面。
- 可生产：金色闪电；可领取：绿色向下箭头；可开启：金色开锁；道具：蓝色星标。冷却时显示时钟并减淡，锁定格没有操作提示。缺体力、没有空位时闪电变淡；无限体力正常显示可生产。
- 生产器按压回弹，产物用360毫秒弧线飞入目标格，再轻轻落定。点击、合成和拖动落定动画同时恢复到柜架皮肤。
- 弹窗、后台和拖动期间暂停呼吸；系统减少动态效果时保留静态标记。容器和资源仍先选中、再使用，保护可合成物品。

不改变数值、产出规则、存档格式、物品原图、63格布局或经典/新风格共享进度。

## 验证

135项Node测试通过；既有13项真实浏览器玩法检查通过；专用动效浏览器检查覆盖WebP/SVG呼吸、真实生产与连续点击、暂停/恢复、减少动态效果、资源/有限生产器/道具提示、冷却到期、拖动合成、QA存档隔离，以及375×667、768×667、1280×900无缝正方形棋盘。

`results.json` 是专用浏览器检查结果，`gameplay-results.json` 是原有玩法检查结果。已查看实际截图，包含正常开局、生产飞行、经典风格和多种交互状态。`motion-demo.webm` 是真实浏览器检查录像；交互状态截图使用独立本地QA存档。
