## 预览

在仓库根目录：

```sh
python3 -m http.server 4193 --bind 127.0.0.1 --directory kitchen-merge/dist
```

打开 http://127.0.0.1:4193/ 。新厨房默认围坐岛台；有既有存档且无偏好默认经典。点击底部手机 → 厨房设置 → 厨房风格，在「经典厨房 / 围坐岛台」间切换。同一地址、同一份进度，刷新记忆选择。
