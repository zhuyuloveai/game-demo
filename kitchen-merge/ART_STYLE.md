# 小狗厨房 · 美术风格规范

一句话：白色线条小狗店长经营奶油暖光厨房，原木桌面、陶瓷与玻璃实物入口；物品保留现有插画，通过前后层次、柔光和动效突出。

环境厨房已接入 `main`，设计说明见 `docs/ENVIRONMENT_UI.md`。场景由 `dist/scene.css`、`dist/island.css` 和 `dist/classic.css` 管理，基础组件及物品动效由 `dist/style.css` 管理。

## 1. 整体语言

- 底色使用奶油、暖瓷与浅木色；文字为暖棕。经典厨房沿用奶油环境；围坐岛台以窗光、水槽、木台面与浅蓝柜体组成连续空间。
- 唯一强调色柿橙 `--accent: #ee6a3f`（深色版 `#d9552c`，浅底 `#fdeee7`）。强调色只用在：主按钮、可交付订单、选中态、生产器徽标。
- 功能色只有两种：成功用鼠尾草绿 `#5f9157`，金币/星星用金色 `#e8a93b`。
- 层级靠真实物件形状、厚度、接触阴影和前后遮挡；卡片组件用于物件打开后的详细内容。
- 主标题和物件文字用自托管站酷快乐体 `--cute-font`；长说明和资源数字使用系统字体，数值保持易读。字体许可在 `docs/fonts/`。
- 底部是可交互的木桌物件：食谱、橱柜、手机与收音机；小狗店长与礼物位于主线旁，点击小狗打开手札。柜子开门、书页翻动、音乐旋钮微光和小狗待机动画保留自然反馈。
- 料理台采用一体奶油棋盘：沿用暖灰米色底，用同色系的轻微明暗交替提示七列九行的63个正方形格位。格子无间隙、无独立白色卡片，物品以较饱满的显示比例和短软影突出；选中、落点和提示高亮画在格内。棋盘抬高为有侧壁的厚奶油料理板，底部木桌分层；物品图稿保持原有设计。
- 生产器与资源靠插画识别，等级和剩余次数放在详情/图鉴，不恢复彩色卡片底；冷却降饱和、锁定纹理和气泡膜保留。按压与弹出缩放只作用于图稿，棋格本体保持连续。
- 待机动效按物品 ID 错峰：可生产厨具每 3.2 秒轻呼吸，选中/提示物品轻浮动，资源物品每 4.8 秒短暂摇摆；等级、礼物徽标轻跳，可交付按钮轻弹并扫光。内层 SVG 做待机，外层图稿做点击挤压、生产弹出、合成回弹，避免抢占同一 transform。拖拽暂停棋盘待机，冷却生产器停止呼吸，打开面板或页面隐藏时暂停背景动画；尊重系统「减少动态效果」，并停止生成装饰粒子。

## 2. 物品插画（`dist/art.mjs`）

- 造型只画轮廓几何（80×80 视图），材质由管线统一渲染：画什么颜色不重要，**归属哪个材质才重要**。
- 每类物品映射到一种材质（`THEME_OF` 表）：餐具→灰蓝釉陶 `glaze`，烤箱→暖白珐琅 `porcelain`，篮筐→藤编 `rattan`，花盆→赤陶 `terracotta`，草莓/果酱→浆果红 `berry`，厨师机→鼠尾草绿 `sage`，机器→金属灰 `steel`，礼盒/商店→柿橙 `persimmon`，便当→深漆红 `lacquer`，布艺→亚麻 `linen`。
- 管线自动处理：粉色旧色按材质重映射 → 体积渐变（左上亮、右下暗）→ 同色系 1.5px 细描边（55% 不透明度）→ 统一落地投影。渐变定义全页只注入一次，不要手写 `id`。
- 新增物品三步：① 在 `art` 里画平色剪影；② 在 `THEME_OF` 里登记材质；③ 用图鉴总览确认 84px 和 48px 两档都清晰。`icon('不存在的名字')` 会回退到星星，顺手检查拼写。
- 食物色不许灰：番茄、草莓、胡萝卜保持饱和，绿色只用新鲜叶绿，奶油/面粉保持近白。
- 顾客头像与物品分开画（`bear/deer/panda/bunny/kitty`，主题 `raw` 不进管线）。

## 3. 界面图标与场景

- 简单界面图标使用 `glyph()`；环境入口以实物识别，书封及包裹可复用原有物品插画。顶层电表、小猪和星星罐用 CSS 构形。电表为圆角方形奶油外壳、浅灰绿液晶屏、闪电与指示灯；小猪背部投币口插着半枚金币。
- 小狗店长复用用户本机 Codex 自定义宠物「M 帽小狗」的白色线条形象。动画图原样复制为 `dist/assets/puppy-sprites.webp`，使用 CSS 帧定位；左上角头像和桌面吉祥物来自同一张图。保留原来的帽子与线条，避免重新描摹导致形象不一致。左上角等级沿用游戏经验计算。
- 两种主题共用100dvh紧凑布局并计入安全区，375×667内容视口中完整显示7×9棋盘与主要入口、无纵向页面滚动；方格等大、不加透视。只有订单区横滑，弹窗独立滚动。顶部46px、订单73px、详情44px、棋盘约337×433、底部60px。空间不足时按高度约束棋盘宽度。
- 岛台完整场景与四个底部物件使用内置imagegen生成并压缩为自托管WebP；经典保留原CSS物件。不同主题共用同一引擎和存档，通过手机设置即时切换。
- 庆祝彩纸五色：`#f0643c #f6b84b #8fb07a #9fb3c4 #f7efe4`；生产器等级在详情/图鉴中显示，不覆盖物品。

## 4. 文案与文件

- 用户可见资源名称统一为「体力」「金币」「许愿星」「彩虹糖」。旧存档及引擎字段保持兼容，新增岛台场景集中在 `island.css`，经典外观在 `classic.css`。
- 游戏与厨房标识统一为「小狗厨房」，吉祥物称「小狗店长」。品牌更名保留 `little-kitchen-save-v1`、旧档备份键和原声音偏好键。
