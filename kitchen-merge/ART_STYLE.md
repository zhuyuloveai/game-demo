# 小厨合合 · 美术风格规范

一句话：暖瓷白底、石墨文字、单一柿橙强调色；物品画立体小物，界面只用留白和柔光区分层级。

改动分支：`feat/kitchen-merge-refined-art`（已合入 `main`）。本文档与实现保持一致，后续改美术先读这里。

## 1. 整体语言

- 底色暖瓷白 `--canvas: #f4f1ec`，卡片纯白，文字石墨三级：`#1d1d1f` / `#6f6a64` / `#a59f97`。
- 唯一强调色柿橙 `--accent: #ee6a3f`（深色版 `#d9552c`，浅底 `#fdeee7`）。强调色只用在：主按钮、可交付订单、选中态、生产器徽标。
- 功能色只有两种：成功用鼠尾草绿 `#5f9157`，金币/星星用金色 `#e8a93b`。
- 层级靠圆角（10/14/18/24px）+ 两档柔和阴影 `--shadow-1/2`，**不使用有色描边和色块边框**。
- 字体用系统栈（SF / 苹方 / Noto Sans SC），标题字重 700、字距 -0.02em，数字用 tabular-nums。
- 底部是毛玻璃标签栏，弹窗是分组卡片式面板。动效用弹簧曲线 `--spring`，时长 0.2–0.45s。

## 2. 物品插画（`dist/art.mjs`）

- 造型只画轮廓几何（80×80 视图），材质由管线统一渲染：画什么颜色不重要，**归属哪个材质才重要**。
- 每类物品映射到一种材质（`THEME_OF` 表）：餐具→灰蓝釉陶 `glaze`，烤箱→暖白珐琅 `porcelain`，篮筐→藤编 `rattan`，花盆→赤陶 `terracotta`，草莓/果酱→浆果红 `berry`，厨师机→鼠尾草绿 `sage`，机器→金属灰 `steel`，礼盒/商店→柿橙 `persimmon`，便当→深漆红 `lacquer`，布艺→亚麻 `linen`。
- 管线自动处理：粉色旧色按材质重映射 → 体积渐变（左上亮、右下暗）→ 同色系 1.5px 细描边（55% 不透明度）→ 统一落地投影。渐变定义全页只注入一次，不要手写 `id`。
- 新增物品三步：① 在 `art` 里画平色剪影；② 在 `THEME_OF` 里登记材质；③ 用图鉴总览确认 84px 和 48px 两档都清晰。`icon('不存在的名字')` 会回退到星星，顺手检查拼写。
- 食物色不许灰：番茄、草莓、胡萝卜保持饱和，绿色只用新鲜叶绿，奶油/面粉保持近白。
- 顾客头像与物品分开画（`bear/deer/panda/bunny/kitty`，主题 `raw` 不进管线）。

## 3. 界面图标与场景

- 界面 chrome 一律用 `glyph()` 单色线性符号（24 网格、1.75 线宽、继承文字颜色），不许复用彩色物品图做按钮。
- 装修场景是北欧风厨房底图 + 8 个升级部件叠加；banner 里只取右侧局部，加左侧渐隐。新增装修部件沿用旧几何写法即可，颜色走 `glaze` 管线。
- 庆祝彩纸五色：`#f0643c #f6b84b #8fb07a #9fb3c4 #f7efe4`；生产器等级徽标写作 `Lv1`（特殊符号在部分字体下会乱码）。

## 4. 文案与文件

- 文案不许出现「粉色」等旧主题词；色值只许出现在 `style.css` 顶部变量和 `MATERIALS` 表，不许散落硬编码。
