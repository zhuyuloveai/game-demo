# 小厨合合 · 世界美食厨房

粉色厨房主题的竖屏合成经营小游戏。原生 HTML、CSS、JavaScript，无需安装依赖或构建。

试玩：[http://1.92.214.23/](http://1.92.214.23/)（hw-gw-1 的 80 端口）。部署与回滚见 [deploy/README.md](deploy/README.md)。

## 本地运行

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:4173/ 。ES Modules 需要通过 HTTP 打开。

## 玩法

- 点击生产器消耗 1 体力获取物品；生产器有次数和冷却，同种同级可合并至 4 级。
- 相同种类、等级的物品两两合成。支持触摸拖动，以及先点来源再点目标。拖到不同物品会交换。
- 11 类普通合成链、共 66 级物品：烘焙、厨具、蔬菜、水果、咖啡、餐具、香草、中式、日式、意式、墨西哥料理。另有体力、金币、礼盒合成链，共 77 种图鉴物品。
- 7 类生产器通过装修和商店获得，部分有伴生产物；香草花盆会向相邻空格自然生长，离线最多补产 3 份。
- 10 道食谱把多个类别的食材与厨具关联。烹饪消耗准确数量的食材，保留可反复使用的厨具；更高级厨具也能使用。
- 交付订单得金币、经验与星星；每 3 单获得礼盒。8 阶段装修逐步解锁设备和改变厨房插画。
- 锁定物品可通过相同物品合成解锁，空的锁定格可通过相邻合成解锁，也可花金币整理。
- 仓库可收纳及扩容；每日开店礼、采购铺、礼盒队列、剪刀、沙漏、限时泡泡均可使用。台面满时礼物不会丢失。
- 体力每 30 秒恢复 1 点，自然恢复上限 100；礼物和商店补给可超过上限。
- 原创 Web Audio 16 小节轻快配乐，点击、生产、移动、合成、交单、做菜、解锁、装修等音效；点击光圈、弹跳、彩纸、蒸汽与闪光特效。首次操作后启用声音，音乐和音效分别开关及调节音量，隐藏页面暂停配乐。
- 当前浏览器自动存档，兼容并备份原 v1 进度。不同设备或站点的进度独立。

## 机制参考与实现范围

参考了《肥鹅健身房》的合成经营方向，以及生产器、订单、星星建设、资源合成、仓库、辅助道具和空间解锁机制。厨房题材、美术、音乐、配方和数值由本项目制作。清洁用品类别未加入。

资料：[官方 App Store 介绍](https://apps.apple.com/cn/app/id1579028465)、[TapTap 生产器攻略](https://www.taptap.cn/moment/260763709427681258)、[玩家基础机制说明](https://forum.gamer.com.tw/C.php?bsn=77871&snA=35)。

这是单机浏览器版本，当前覆盖主经营循环，没有商业手游的账号服务、付费系统、广告或限时活动服务器。为便于试玩，体力恢复和生产器冷却采用本项目的加快节奏。

## 验证

```sh
node --test tests/engine.test.mjs
node --check dist/app.mjs
node --check dist/audio.mjs
```

35 项规则测试覆盖旧档迁移、生产器、冷却、订单、装修、仓库、配方、每日礼物、辅助道具、离线产出和满盘原子性。所有插画为内联 SVG，音频由 Web Audio 合成，不依赖外部图片、字体或音频服务。
