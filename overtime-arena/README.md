# 下班突围 · Overtime Arena

一个职场题材的网页割草原型：单武器开局、六臂购装合成、20 波生存、人物升级与道具构筑，以及四倍面积的跟随镜头地图。

## 运行

需要 Node.js 22.12+ 或 24 LTS。

```sh
npm install
npm run dev -- --port 5173
```

打开 http://127.0.0.1:5173。开发服务默认仅监听本机。

```sh
npm run build
npm test
npm run preview
```

## 操作

| 操作 | 输入 |
| --- | --- |
| 移动 | 鼠标 / Mac 触摸板滑动控制方向、停手即停；手机触屏在战斗画面按住滑动、停手即停；所有输入均受角色最大移速限制；WASD / 方向键与手柄左摇杆作为备用 |
| 攻击 | 六把武器独立自动索敌、交错攻击，只需专注走位 |
| 暂停 / 释放鼠标 | Esc；工具栏暂停按钮 |
| 继续 | 点击“继续战斗” |
| 重新开始 | 工具栏重新开始按钮 |
| 配置武器 | 开局前选择一件一级武器，局内通过波间商店购买、合成和回收；最多六把 |
| 调整人物属性 | 开局前调整初始攻击力、攻速和暴击，局内选择升级与购买道具 |

桌面点击开始或继续后，浏览器锁定并隐藏鼠标。鼠标与 Mac 触摸板使用连续的相对移动输入，滑动动作控制方向，无需按住左键，也不受画面边缘限制。角色的移动速度有上限，超过本次可移动距离的输入当场丢弃，停手即停。按 Esc 暂停并释放鼠标后，可以调整参数；点击继续恢复时重新锁定。手机触屏直接按住战斗画面滑动，不申请鼠标锁定；抬手后可重新落指继续移动。首次按下与重新落指时，角色位置保持不变；随后滑动带动角色。

“鼠标 / 触控灵敏度”默认 1.0×，可在 0.5×–2.0× 范围调整小幅滑动的响应；“角色最大移速”统一限制鼠标、触控、键盘与手柄的移动。两项设置即时生效并保存在本机浏览器。

鼠标锁定失败时，游戏保持暂停并显示原因，点击“继续战斗”可重新尝试；当前浏览器不支持鼠标锁定时，会提示使用 WASD / 方向键或触屏继续。

切到其他窗口或隐藏标签页会暂停并释放鼠标，返回后手动继续，防止后台丢帧补算与卡键。

## 人物属性与伤害

控制面板和其中五个分类默认收起。人物属性单独保存，六把武器共享加成；“恢复属性”只恢复人物数值，“恢复默认手感”只恢复操作和反馈参数。

| 属性 | 默认值 | 效果 |
| --- | --- | --- |
| 攻击力 | 100 | 每点增加 1% 武器伤害，默认伤害倍率为 2 |
| 攻速加成 | +35% | 每把武器的攻击频率乘以 1.35 |
| 暴击率 | 25% | 暴击造成 2 倍伤害 |

```
最终伤害 = round((武器当前等级伤害 + 对应类型伤害 × 武器系数) × (1 + 攻击力 / 100) × 暴击倍率 × 敌人承伤系数)
攻击间隔 = 武器当前等级间隔 / (1 + 攻速加成 / 100)
```

普通命中的暴击倍率为 1，暴击为 2；盾牌正面承伤系数为 0.42，侧后方为 1。连锁电击先应用逐跳衰减，再进入同一伤害公式。子弹、咖啡爆炸和文件夹往返保留发射时的人物属性与武器等级，新属性作用于之后发起的攻击。

按默认值，一级订书机普通/暴击伤害为 42/84，咖啡爆炸为 136/272；同样命中条件下的理论持续输出约为旧默认值的 3.1 倍。武器卡显示当前等级及人物属性下的单次命中普通伤害、暴击伤害与每秒攻击次数，敌人减伤另算。多弹、穿透、范围和连锁效果会影响实际清怪效率。

攻击力可调 0–300，攻速加成可调 -50%–100%，暴击率可调 0%–100%。旧版存档的默认攻击频率 1× 会采用新的 +35%；手动调整过的旧频率则转换为等效攻速加成，已有新属性优先保留。

## 八种武器与五级成长

生存挑战默认只持有一把一级订书机，其余五只手为空。开局前可以改变第一只手的武器种类，正式挑战始终从一级开始；旧版六槽预设不会免费带入正式局。靶场仍可自由配置六把武器与等级。每把已装备武器拥有独立冷却与索敌，空手不会攻击。

| 武器 | 攻击特点 | 3 级 / 5 级强化 |
| --- | --- | --- |
| 脉冲订书机 | 快速连射，子弹穿透敌人 | 增加穿透目标数 |
| 碎纸霰弹 | 扇形散射，贴身集中命中 | 增加弹丸数 |
| 机械键盘 | 扇形横扫并击退敌群 | 扩大横扫范围 |
| 激光演示笔 | 瞬时直线射线，贯穿多名敌人 | 增加贯穿数和光束宽度 |
| 高压咖啡杯 | 锁定落点，沿抛物线飞行后爆破泼溅 | 扩大爆破范围 |
| 回旋文件夹 | 飞出后返回玩家，往返均可穿透命中 | 增加穿透数和判定范围 |
| 解压印章 | 在近距离目标处圆形重击，震退周围敌人 | 扩大震击范围 |
| 超载充电线 | 就近连锁电击，同次攻击不重复命中同一敌人 | 增加连锁数和跳跃距离 |

五个等级依次为 **1 普通、2 精良、3 稀有、4 史诗、5 传说**，采用白、绿、蓝、紫、金区分。每级提高伤害、攻击频率和击退，3 级与 5 级额外增强对应武器的特点。

局内武器通过商店合成升级：两把同种同级武器合成一把高一级武器，最高五级。默认购买优先填充空手，也可指定同种同级的手直接购买合成；满六槽时，只能购买可以合成的武器。装备区支持手动合成已经持有的两把武器，消耗其中一把并空出一只手。不同武器不能覆盖占用槽，需要先回收装备；回收返还当前同级价格的 25%（向下取整），最后一把不能回收。

前两间商店至少提供两把武器，首店保底有一把 15 加班费的一级武器。价格已按单武器开局的收入重新调整。局内装备不会覆盖本机初始预设，重开回到单把一级武器。

## 20 波成长与商店

“持续来袭”和“密集围攻”采用完整局内流程；“固定靶场”保留自由测试，没有加班费、人物经验或商店。从靶场切换模式会回到开始界面。

1. 普通波坚持到倒计时结束。第一波 20 秒，每波增加 3 秒，最高 60 秒，共 20 波。战斗只需移动，当前持有的武器自动攻击。第 10 与 20 波需要击败 Boss，计时结束后停止普通增援，但 Boss 存活时不会结算。
2. 敌人掉落工资条，同时增加人物经验和加班费。加急文件价值 1，闹钟和投手 2，审批壁垒 3，主管 4。波末自动结清场上掉落，过期或对象池满也不会丢失收益。
3. 经验满足 `20 + 15 × (等级−1) + 2 × (等级−1)²` 时提升一级，强化选择累计到波末。每次从四个不同属性中选一项；免费选择，付费刷新，多次升级逐次选择。
4. 升级完成后进入四格商店，购买武器或职场道具。商品可锁定，刷新和跨波保留原商品与价格；刷新费用随本波次数增加，下一波重置。全锁时不会收取刷新费用。
5. 点击下一波，生命恢复至当前上限，继续保留人物成长、加班费、道具和装备。第 20 波击败 Boss 并选择传说奖励后通关。

死亡规则沿用控制面板：无压力练习默认开启，倒下恢复生命并推开敌人；开局前关闭后，生命耗尽结束本局。两种规则都可以体验完整成长流程。局内不保存断点，刷新页面或重新开始会重置本局成长。

第 10 波 Boss 为 **绩效主管**：8,000 生命，以有红色方向预警的冲锋为主，间隔施放少量短程扇形弹。击败立即获得 200 加班费、80 经验，以及一件免费史诗奖励（三选一），然后继续升级和商店流程。

第 20 波 Boss 为 **加班董事长**：16,000 生命，交替冲锋与短程扇形弹，半血后强化；预警出现后，攻击方向与范围保持锁定。击败获得 600 加班费、200 经验、传说奖励三选一与通关奖杯。Boss 死亡后短暂冻结战斗和伤害，播放击破反馈，再显示奖励；不用等待剩余倒计时。奖杯与战利品显示在本局结算，重开后清空。

人物一共 15 项属性，局内可通过升级和道具成长：

| 类型 | 属性与效果 |
| --- | --- |
| 输出 | 攻击力、攻速、暴击率；近战、远程、元素伤害先按武器系数加到基础伤害 |
| 生存 | 最大生命、生命再生、生命窃取、护甲、闪避 |
| 移动与经济 | 移速加成、拾取范围、幸运、收获 |

近战系数：键盘与印章 1；远程：订书机 0.7、霰弹每颗 0.35、文件夹 0.8；元素：激光笔与咖啡杯 1、电线 0.8。攻击力局内上限 1000%，攻速加成上限 200%，暴击率最高 100%。

护甲为正时受伤除以 `1 + 护甲/15`，负护甲增加伤害；闪避最高 60%。生命再生第一点每秒回复 0.2，后续每点增加 0.089；生命窃取按命中概率回复 1 点，每 0.1 秒最多一次。工资条只提供经验和加班费，回复依靠生存属性和波间休整。移速加成应用于鼠标、触控、键盘和手柄，最终限制在 100–560；基础拾取范围为 140，按范围加成扩大。

幸运提高升级和商店品质概率；高品质随波次逐步解锁。收获默认 5，每波结算给予等量加班费和经验，然后增长 5% 向上取整。16 种原创新道具包括热乎便当、资深工牌、人体工学椅、浓缩咖啡因、绩效奖金、补充医保卡、通勤跑鞋等，带属性取舍和堆叠上限；背包显示数量与效果。

机制参考 [Brotato 官方商店介绍](https://store.steampowered.com/app/1942280/Brotato/) 与社区整理的 [属性](https://brotato.wiki.spellsandguns.com/Stats)、[商店](https://brotato.wiki.spellsandguns.com/Shop)。这里是适配六臂、五级武器与职场主题的原创数值原型，未复刻原作角色和道具素材；平衡仍需实际试玩迭代。

## 画面与个人头像

世界尺寸由 1120×720 扩展到 2240×1440，面积为原来的四倍。视口仍为 1120×720，角色与武器的屏幕比例保持不变；镜头随角色移动并限制在地图边界内。小地图显示人物位置和当前视野，Boss 血条固定在画面上方，全屏模式下也可见。敌人从当前视野外围出现，不会贴身生成；玩家子弹、敌弹与碰撞均使用世界坐标，不受原画面边界限制。鼠标、触屏输入仍按视口比例换算，扩图不会提高移动速度。

场景使用写实办公室背景，角色身体、武器、敌人和战斗反馈使用粗轮廓卡通风格。主角采用三头六臂的夸张打工人造型：三颗照片头像连接卡通身体，六只手各持一把办公武器。三颗头共享同一人物，默认头像根据用户指定的微信女生照片制作，也可以一起换成自己的照片。头像不绘制圆形底板或外框，默认素材保留头发、耳朵和下巴的透明轮廓；表情形变围绕下巴与领口的连接处进行，随身体同步起伏。

三头朝向参考传统三头六臂造像：中央正面，两侧朝外并位于中央头之后，肩颈收拢在同一躯干上。默认人物的透明正面与侧脸素材由指定照片经 image_gen 制作，右侧镜像使用；侧脸表情采用单眼、单眉与侧嘴。游戏面板上传的照片仅在本地进行二维侧向压缩与镜像，不自动生成真实侧脸，也不外发原照片。

开始前或暂停后，在右侧“我的打工人”面板选择 JPG、PNG 或 WebP 照片（最多 10 MB），调整缩放和水平 / 垂直位置，再应用到三颗头上。照片在本机浏览器内解码与裁切成 256×256 的透明圆形 PNG，仅保存裁切后的小图到本地浏览器，不发送到服务器。当前默认人物使用独立的本地头像记录，首次刷新会显示新人物；旧版头像记录保留。恢复默认会清除当前人物下保存的头像。

头像支持平静、暴躁、愤怒、惊恐、得意五种预览；战斗中攻击、受击和暴击会触发表情。怪物贴近时会自动露出愤怒表情，远离后恢复；受击时的惊恐表情优先显示。当前表情使用照片挤压、拉伸、歪头以及漫画眉眼、嘴型、汗滴和符号，属于本地动画，不调用 AI 重新生成上传照片的五官。

身体采用分部件的程序动画，动作会按移动速度与战斗事件平滑混合：

| 动作 | 表现 |
| --- | --- |
| 呼吸待机 | 胸口轻微起伏，领带与手臂小幅跟随 |
| 起步跑步 | 双腿交替迈步，六只持械手臂分层跟随，身体随步频弹起并前倾 |
| 急停转向 | 停下时回弹收势，转向时肩胯与头部错开跟随 |
| 射击后坐 | 发射时肩膀与手臂短促后缩，再平滑回位 |
| 近战挥击 | 挥击带动手臂与上身扭转，收势连回移动动作 |
| 受击回弹 | 身体沿受力方向偏移、压缩并回弹 |

这些动作均自动触发，战斗中只需移动。

背景和默认头像素材位于 `public/assets/`，完整生成提示词与来源记录见 `public/assets/ART-PROMPTS.txt`，使用 built-in image_gen 生成。办公室家具位于外围，中央保留可战斗空间。

## 敌群与压力

持续来袭与密集围攻按六把武器的火力增强了敌群强度，并混合五类敌人：

| 敌人 | 特点与应对 |
| --- | --- |
| 加急文件 | 快速追击，持续移动避免被包围 |
| 重装主管 | 高血量并抵抗击退，需要持续集火 |
| 催命闹钟 | 红线预警 0.6 秒后沿锁定方向冲锋，横向走位避开 |
| 甩锅投手 | 预警 0.75 秒后发射一枚短程慢弹，侧向走位避开 |
| 审批壁垒 | 正面减伤，绕到侧后方可正常造成伤害 |

压力来源面板显示当前波次。前三波没有弹幕怪，第 4–7 波最多一只；后续逐步增加，最多五只。普通射手每次只发一枚，速度 180、寿命 1.5 秒，最大飞行距离 270（原来约 874），攻击间隔 3.2 秒，预警与实际射程一致。开局按单武器重新调低敌人血量和密度，持续来袭与密集围攻随后按波次增长，成长与同屏数量有上限。攻击预警保留躲避时间，战斗中依然只需移动。固定靶场保持静态练习目标，不随时间成长，也不生成敌弹，面板显示“靶场”。无压力练习仍在生命耗尽时恢复血量并推开敌群。

## 当前范围

- 八种办公武器、单把一级开局、六个装备槽、五级合成成长、20 波挑战、两个 Boss、15 项人物属性与 16 种商店道具及 Boss 专属奖励。战斗中只需移动，波间选择升级与购物。
- 120 Hz 固定步长战斗模拟、渲染插值、键盘 / 手柄输入归一化。
- 桌面使用浏览器 Pointer Lock 获取无边界的相对移动输入；Esc 暂停释放，恢复时重新申请。触屏继续使用按住滑动。
- 鼠标 / 触控根据滑动方向与小幅位移响应移动，输入到达时按实时速度上限执行；多余位移当场丢弃，下一次渲染显示当前位置，停手后没有补走。
- 简单敌群分离、五类行动各异的敌人、按波次增长且有上限的敌群压力、固定靶场和密集围攻。
- 连续线段碰撞防高速子弹穿透目标；首次扫掠覆盖对应持械手至枪口区间。鼠标 / 触控移动角色时也检查整段路径，经过敌人时仍会受伤。
- 命中闪白、击退、暴击浮字、碎屑、枪口火光、斩击弧、连击提示和拾取反馈。
- 本地合成音效，不依赖外部媒体或音频服务。
- 实时调整鼠标 / 触控灵敏度、角色最大移速、击退、震屏、音量；参数保存在浏览器本地。
- 无压力练习默认开启：生命耗尽时恢复并推开敌人；关闭后耗尽生命结束本局。
- 敌人最多 240、玩家子弹最多 300、咖啡杯与回旋文件夹合计最多 72、敌弹最多 120、拾取物最多 160、粒子最多 540、伤害浮字最多 28。
- HUD 显示 FPS 与最近 180 个活动显示帧的 P95 帧间隔。P95 包含浏览器调度时间，不能等同于纯 CPU/GPU 渲染耗时。

## 技术结构

- TypeScript + Phaser 3.90 + Vite，WebGL 渲染。
- `src/main.ts`：引擎启动与缩放。
- `src/shared.ts`：界面/游戏事件契约与默认参数。
- `src/ui.ts`、`src/style.css`：控制界面、六槽配装与等级经验展示、本地参数和起始装备保存。
- `src/game/CombatScene.ts`：固定步长模拟、输入、武器、敌群、对象复用。
- `src/game/WeaponRig.ts`：六把武器的独立冷却、索敌与出手节奏。
- `src/game/WeaponModel.ts`：八种武器的五级属性、经验阈值与配装校验。
- `src/game/PlayerModel.ts`：15 项人物属性、旧参数迁移、伤害与生存公式、武器输出预测。
- `src/game/RunModel.ts`：20 波生命周期、经验升级、道具目录、商店、回收、锁定、货币、武器合成与 Boss 战利品。
- `src/game/WorldModel.ts`：世界尺寸、跟随镜头边界和安全出生点。
- `src/game/BossModel.ts`、`BossTextures.ts`：两种 Boss 的独立行为、预警参数与卡通纹理。
- `src/game/WeaponAttacks.ts`：射线穿透顺序、连锁目标选择与范围命中几何。
- `src/game/PlayerMotion.ts`、`src/game/PlayerBody.ts`：按位移推进的步态、动作混合、分部件身体与头像/武器连接点。
- `src/game/Feedback.ts`：有数量上限的视觉与 WebAudio 反馈。
- `src/avatar.ts`：本地照片校验、裁切和安全恢复。
- `src/game/PhotoHead.ts`：三颗照片头像、共享纹理替换和漫画表情反馈。
- `src/game/math.ts`：连续碰撞、空间索引、输入方向计算。
- `src/game/textures.ts`：程序生成的敌人、武器、粒子纹理与场景布置。

第一阶段验收重点：起停与转向、贴身命中可靠性、八种攻击节奏、五级成长、连续击破反馈，以及目标设备上的帧时间稳定。场景美术、剧情、职业差异、道具联动与关卡内容继续扩展。

## 试玩记录建议

每次只改一个参数，并记录敌群模式、灵敏度/移速/攻速/击退、设备浏览器，以及“偏飘 / 偏重 / 反馈太弱 / 画面太乱”的具体发生时机。优先比较同一配置下的一分钟体验。

## 验证状态

构建和模型/场景逻辑回归覆盖武器空槽、单武器开局、购买合成与回收、10/20 波 Boss 结算、奖励防重复、世界坐标碰撞、Boss 擦边命中、镜头边界、安全出生和鼠标限速。场景集成测试执行真实战斗代码，只替换渲染、音频和浏览器输入接口。

初步平衡模拟以三个固定随机种子、默认属性、生存模式和绕圈输入运行：首波收入 30–33，可以购买两把 15 加班费的武器；前三波均能存活且逐步补齐装备。Boss 使用明确的六把 Lv.2–3 武器与成长属性样本单独模拟，验证真实自动攻击可以击败 Boss 并进入奖励流程。模拟用于排查经济断档与明显强度问题，不能替代完整玩家体验。

浏览器自动化访问受当前工具的已保存权限规则阻止，因此尚未完成真实浏览器的镜头观感、画面、音频、手柄与触屏实测，也不宣称已达到特定性能指标。
